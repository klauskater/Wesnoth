# Контракт универсального мира

## Координаты и hex-сетка

Карта — прямоугольный массив гексов с 1-based координатами. `(1,1)` — верхняя
левая клетка, `x` растёт вправо, `y` — вниз. Используется вертикальная сетка с
поднятыми чётными 1-based столбцами (upper odd-q в zero-based записи).

Соседи клетки всегда включают `(x,y-1)` и `(x,y+1)`. Диагонали зависят от `x`:

- нечётный столбец: `(x-1,y)`, `(x-1,y+1)`, `(x+1,y)`, `(x+1,y+1)`;
- чётный столбец: `(x-1,y-1)`, `(x-1,y)`, `(x+1,y-1)`, `(x+1,y)`.

Координаты за прямоугольником недопустимы и не возвращаются `neighbors`.

## Карта

Каждая клетка хранит исходный строковый код WML. Rust предоставляет:

```text
Map::raw(position) -> исходный код
Map::get(position) -> нормализованный игровой тип
Map::are_adjacent(a, b) -> boolean
Map::neighbors(position) -> позиции в границах карты
```

Lua получает только нормализованное представление:

```lua
context.map:get(position) -> gameplay_type
context.map:are_adjacent(a, b) -> boolean
context.map:neighbors(position) -> [{ x, y }]
```

`gameplay_type` сводит исходные коды к `grassland`, `forest`, `hills`, `water`,
`castle`, `keep` или `village`; неизвестный код становится `grassland`.
Графический клиент продолжает использовать исходный код независимо от этой
классификации.

## Объекты

Объект имеет уникальный строковый `id` и произвольную карту свойств. Движок не
приписывает свойствам игрового смысла.

```lua
context.objects:get(id) -> snapshot | nil
context.objects:set(id, property, value)
context.objects:add({ id=string, ... })
context.objects:remove(id)
context.objects:all() -> [snapshot]
```

`get` и `all` возвращают снимки: их изменение не меняет мир. `set` требует
существующий объект. `add` требует строковый id и отклоняет повтор. `remove`
требует существующий id. `all` возвращает объекты в лексикографическом порядке
id, потому что хранилище является `BTreeMap`.

Позиция — обычное свойство `{x,y}`. Занятость клеток и допустимость размещения
проверяют конкретные Lua-правила, а не хранилище.

## Состояние

Изменяемое состояние сценария отделено от объектов:

```lua
context.state:get(key) -> value | nil
context.state:set(key, value)
```

Ключ — строка, значение — любой поддерживаемый `Value`. Запись `nil` сохраняет
значение `Nil`; она не удаляет ключ из Rust-карты. Пространство `campaign:`
переносится между главами, остальные ключи принадлежат текущему сценарию.

Все изменения объектов, состояния и RNG фиксируются только при успешном
завершении одной команды; подробности определены в [lua-runtime.md](lua-runtime.md).
