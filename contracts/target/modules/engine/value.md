# Контракт engine/value

Статус: **реализован**. Редакция проекта: 1. Строгий Rust/Lua round trip и
`wesnoth.value.list/record/null` сохраняют явные типы, включая пустые значения.
Поставщик: `src/engine/value.rs`.
[Карточка модуля](../../../../design/architecture/modules/engine/value.md).
Обязательны [общие соглашения](../../common.md) и [поток сообщений](../../stream.md).

## Назначение

Общие сериализуемые значения и преобразование на границе Lua.

## Потребители и зависимости

Потребители: [engine/protocol](../engine/protocol.md), [engine/store](../engine/store.md), [engine/runtime](../engine/runtime.md), [engine/data_format](../engine/data_format.md), [engine/persistence](../engine/persistence.md).

Использует контракты: нет внутренних зависимостей.
Ссылка Lua → engine означает возможность host API через ctx, а не импорт Rust из Lua.
Обратная ссылка потребителя не разрешает обратный вызов или циклический импорт.

## Операции: вход → выход

```text
to_lua(Value) -> LuaValue
from_lua(LuaValue) -> Value
encode/decode(Value) -> data/Value
```

Это обязательные логические формы, не готовые Rust-сигнатуры. Общие типы определены
в common.md; специфичные типы текущей игры используют её сохранённую семантику,
описанную в [таблице соответствия](../../README.md#прежние-документы).
Конкретный wire layout и имена полей этих игровых записей уточняются в данном
контракте до переключения вызывающих, а не скрыто внутри реализации.

## Гарантии и результат

Целевой Value: Null, Bool, Int(i64), Number(конечный f64), String, List, Record<String,Value>. Number нужен для вероятностей и визуальных величин. List/Record, включая пустые, различаются; явный Null внутри коллекции не равен отсутствующему ключу.

## Ошибки и побочные эффекты

NaN/Infinity, функция, userdata, цикл или неоднозначная смешанная таблица -> Error. Bridge обязан задать явные конструкторы list/record/null для неоднозначных Lua-значений; точное Rust/Lua написание фиксируется до M06.

## Владение данными

Представление чисел, строк, списков, записей и null.

## Что не входит в контракт

Не содержит методов unit.hp или толкования игровых полей.

## Приёмка реализации

Вложенное значение сохраняет типы при round trip; неподдерживаемое значение приводит к ошибке до commit.

Перенос из: src/value.rs.
При внедрении добавить ссылку `Контракт: contracts/target/modules/engine/value.md`
в заголовок файла поставщика. Статус меняется на «реализован» только вместе
с реализацией, переведёнными потребителями и результатом проверки.
