# Контракт engine/data_format

Статус: **реализован**. Редакция проекта: 1.
Поставщик: `src/engine/data_format.rs`.
[Карточка модуля](../../../../design/architecture/modules/engine/data_format.md).
Обязательны [общие соглашения](../../common.md) и [поток сообщений](../../stream.md).

## Назначение

Синтаксический разбор декларативных ресурсов.

## Потребители и зависимости

Потребители: [engine/resources](../engine/resources.md).

Использует контракты: [engine/value](../engine/value.md).
Ссылка Lua → engine означает возможность host API через ctx, а не импорт Rust из Lua.
Обратная ссылка потребителя не разрешает обратный вызов или циклический импорт.

## Операции: вход → выход

```text
parse(text) -> DataNode[] | ParseError
```

Это обязательные логические формы, не готовые Rust-сигнатуры. Общие типы определены
в common.md; специфичные типы текущей игры используют её сохранённую семантику,
описанную в [таблице соответствия](../../README.md#прежние-документы).
Конкретный wire layout и имена полей этих игровых записей уточняются в данном
контракте до переключения вызывающих, а не скрыто внутри реализации.

## Гарантии и результат

DataNode = {name, attributes: Map<String,String>, children: DataNode[]}; порядок детей сохраняется. Синтаксис — существующий WML subset; типизация атрибутов и семантика тегов выполняются Lua.

## Ошибки и побочные эффекты

Неверная вложенность/атрибут -> ошибка с позицией; неизвестный игре тег не является синтаксической ошибкой. Парсер не читает файлы и не исполняет Lua.

## Владение данными

Только формат дерева; семантика тегов принадлежит Lua.

## Что не входит в контракт

Не требует [unit], [scenario] или [race]. Не применяет игровые значения по умолчанию.

## Приёмка реализации

Неизвестный игре тег можно синтаксически разобрать; ошибочная вложенность диагностируется.

Перенос из: src/wml.rs.
При внедрении добавить ссылку `Контракт: contracts/target/modules/engine/data_format.md`
в заголовок файла поставщика. Статус меняется на «реализован» только вместе
с реализацией, переведёнными потребителями и результатом проверки.
