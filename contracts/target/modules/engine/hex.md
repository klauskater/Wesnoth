# Контракт engine/hex

Статус: **реализован**. Редакция проекта: 1.
Поставщик: `src/engine/hex.rs`.
[Карточка модуля](../../../../design/architecture/modules/engine/hex.md).
Обязательны [общие соглашения](../../common.md) и [поток сообщений](../../stream.md).

## Назначение

Геометрия гексагональной сетки.

## Потребители и зависимости

Потребители: [engine/store](../engine/store.md), [engine/runtime](../engine/runtime.md), [engine/pathfinding](../engine/pathfinding.md), [client/viewport](../client/viewport.md).

Использует контракты: нет внутренних зависимостей.
Ссылка Lua → engine означает возможность host API через ctx, а не импорт Rust из Lua.
Обратная ссылка потребителя не разрешает обратный вызов или циклический импорт.

## Операции: вход → выход

```text
neighbors(bounds, position) -> Position[]
distance(a,b) -> Int
adjacent(a,b) -> Bool
contains(bounds,p) -> Bool
```

Это обязательные логические формы, не готовые Rust-сигнатуры. Общие типы определены
в common.md; специфичные типы текущей игры используют её сохранённую семантику,
описанную в [таблице соответствия](../../README.md#прежние-документы).
Конкретный wire layout и имена полей этих игровых записей уточняются в данном
контракте до переключения вызывающих, а не скрыто внутри реализации.

## Гарантии и результат

Координаты и соседство из действующего world.md сохраняются: 1-based upper odd-q. neighbors возвращает только клетки карты; distance — геометрическое расстояние без terrain.

## Ошибки и побочные эффекты

Недопустимые размеры/позиция для ограниченного запроса -> Error; чистое distance допускает позиции вне карты. Операции не читают мир.

## Владение данными

Геометрические типы и конверсия координат, без игровых свойств ячеек.

## Что не входит в контракт

Не превращает код terrain в village/forest и не задаёт стоимость хода.

## Приёмка реализации

Соседство и расстояния согласованы на краях и для чётных/нечётных столбцов.

Перенос из: Map/Position в src/engine.rs; геометрические helpers Lua.
При внедрении добавить ссылку `Контракт: contracts/target/modules/engine/hex.md`
в заголовок файла поставщика. Статус меняется на «реализован» только вместе
с реализацией, переведёнными потребителями и результатом проверки.
