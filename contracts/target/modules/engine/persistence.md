# Контракт engine/persistence

Статус: **реализован**. Редакция проекта: 1. Версионированный формат, typed errors, identity
пакета и полный StoreSnapshot подключены к Session; restore не вызывает initialize,
read-only Lua-валидация выполняется до атомарной замены Store.
Поставщик: `src/engine/persistence.rs`.
[Карточка модуля](../../../../design/architecture/modules/engine/persistence.md).
Обязательны [общие соглашения](../../common.md) и [поток сообщений](../../stream.md).

## Назначение

Запись и восстановление согласованного снимка сессии.

## Потребители и зависимости

Потребители: [engine/session](../engine/session.md).

Использует контракты: [engine/store](../engine/store.md), [engine/resources](../engine/resources.md), [engine/value](../engine/value.md).
Ссылка Lua → engine означает возможность host API через ctx, а не импорт Rust из Lua.
Обратная ссылка потребителя не разрешает обратный вызов или циклический импорт.

## Операции: вход → выход

```text
encode(package_identity, StoreSnapshot) -> SaveBytes
decode(bytes, installed_package) -> StoreSnapshot
```

Это обязательные логические формы, не готовые Rust-сигнатуры. Общие типы определены
в common.md; специфичные типы текущей игры используют её сохранённую семантику,
описанную в [таблице соответствия](../../README.md#прежние-документы).
Конкретный wire layout и имена полей этих игровых записей уточняются в данном
контракте до переключения вызывающих, а не скрыто внутри реализации.

## Гарантии и результат

Снимок включает все mutable коллекции, RNG, версию формата и идентичность пакета; кеш view/VM не входит. Session выполняет read-only Lua-валидацию восстановленного мира до публикации.

## Ошибки и побочные эффекты

Неподдерживаемая версия, повреждённые данные, несовместимый пакет -> Error без изменения текущей сессии. Decode не вызывает initialize, доход, traits или carryover.

## Владение данными

Формат сохранения. Сценарий, pending choices и переносимые бойцы — непрозрачные данные store.

## Что не входит в контракт

Не выбирает переносимых ветеранов, размер золота или следующую главу. Не сохраняет кеш UI и текстуры.

## Приёмка реализации

Сохранение посреди выбора восстанавливает выбор; продолжение воспроизводит RNG. Несовместимая версия не загружается молча.

Перенос из: SavedGame и save/load_save в src/game.rs.
При внедрении добавить ссылку `Контракт: contracts/target/modules/engine/persistence.md`
в заголовок файла поставщика. Статус меняется на «реализован» только вместе
с реализацией, переведёнными потребителями и результатом проверки.
