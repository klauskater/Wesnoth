# Контракт engine/pathfinding

Статус: **реализован**. Редакция проекта: 1. Поиск принимает только bounds,
origin, бюджет, стоимости клеток, blocked и stop_cells; игровые MP/ZOC/terrain
готовятся Lua одним пакетом, callback на посещённую клетку отсутствует.
Поставщик: `src/engine/pathfinding.rs`.
[Карточка модуля](../../../../design/architecture/modules/engine/pathfinding.md).
Обязательны [общие соглашения](../../common.md) и [поток сообщений](../../stream.md).

## Назначение

Пакетный поиск по заданному графу гексов.

## Потребители и зависимости

Потребители: [engine/runtime](../engine/runtime.md), [lua/movement](../lua/movement.md).

Использует контракты: [engine/hex](../engine/hex.md).
Ссылка Lua → engine означает возможность host API через ctx, а не импорт Rust из Lua.
Обратная ссылка потребителя не разрешает обратный вызов или циклический импорт.

## Операции: вход → выход

```text
search({bounds, origin, budget, costs, blocked, stop_cells}) -> {costs, predecessors}
```

Это обязательные логические формы, не готовые Rust-сигнатуры. Общие типы определены
в common.md; специфичные типы текущей игры используют её сохранённую семантику,
описанную в [таблице соответствия](../../README.md#прежние-документы).
Конкретный wire layout и имена полей этих игровых записей уточняются в данном
контракте до переключения вызывающих, а не скрыто внутри реализации.

## Гарантии и результат

Стоимость входа — неотрицательное целое; blocked исключает вход, stop_cells разрешает вход и запрещает продолжение. Origin имеет стоимость 0; равные пути разрешаются стабильным порядком соседей; отсутствие достижимости — отсутствие записи.

## Ошибки и побочные эффекты

Неполные веса, неверная позиция или отрицательный budget -> Error. Нет Lua callback на посещённую клетку; функция не интерпретирует MP/ZOC.

## Владение данными

Только временные структуры алгоритма.

## Что не входит в контракт

Не знает MP, ZOC, союзов и terrain. Не вызывает Lua для каждого посещённого гекса; все веса и ограничения переданы пакетом.

## Приёмка реализации

Разные наборы весов дают разные маршруты без изменения Rust; число callback на ячейку равно нулю.

Перенос из: src/pathfinding.rs.
При внедрении добавить ссылку `Контракт: contracts/target/modules/engine/pathfinding.md`
в заголовок файла поставщика. Статус меняется на «реализован» только вместе
с реализацией, переведёнными потребителями и результатом проверки.
