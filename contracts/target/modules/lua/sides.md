# Контракт lua/sides

Статус: **целевой, не реализован**. Редакция проекта: 1.
Поставщик: `scripts/game/rules/sides.lua`.
[Карточка модуля](../../../../design/architecture/modules/lua/sides.md).
Обязательны [общие соглашения](../../common.md) и [поток сообщений](../../stream.md).

## Назначение

Стороны, принадлежность и отношения между ними.

## Потребители и зависимости

Потребители: [lua/flow](../lua/flow.md), [lua/movement](../lua/movement.md), [lua/combat](../lua/combat.md), [lua/turns](../lua/turns.md), [lua/economy](../lua/economy.md), [lua/visibility](../lua/visibility.md), [lua/scenario](../lua/scenario.md), [lua/campaign](../lua/campaign.md), [lua/ai](../lua/ai.md), [lua/interaction](../lua/interaction.md), [lua/hud](../lua/hud.md).

Использует контракты: [engine/store](../engine/store.md).
Ссылка Lua → engine означает возможность host API через ctx, а не импорт Rust из Lua.
Обратная ссылка потребителя не разрешает обратный вызов или циклический импорт.

## Операции: вход → выход

```text
active_side(read) -> SideId
allied(read,a,b) -> Bool
enemies(read,a,b) -> Bool
controller(read,id) -> Controller
side_config(read,id) -> Side
```

Это обязательные логические формы, не готовые Rust-сигнатуры. Общие типы определены
в common.md; специфичные типы текущей игры используют её сохранённую семантику,
описанную в [таблице соответствия](../../README.md#прежние-документы).
Конкретный wire layout и имена полей этих игровых записей уточняются в данном
контракте до переключения вызывающих, а не скрыто внутри реализации.

## Гарантии и результат

Стороны и team overrides читаются из одного store. Вызовы не запускают ходы и AI.

## Ошибки и побочные эффекты

Неизвестная сторона -> Error; один side союзник самому себе. Нет изменений данных.

## Владение данными

Схема сторон и союзов; изменения хранятся в store.

## Что не входит в контракт

Не запускает AI, не завершает ход и не строит UI.

## Приёмка реализации

Изменение союза одинаково учитывается боем, видимостью и AI.

Перенос из: side_team/allied/side_config в basic_combat.lua.
При внедрении добавить ссылку `Контракт: contracts/target/modules/lua/sides.md`
в заголовок файла поставщика. Статус меняется на «реализован» только вместе
с реализацией, переведёнными потребителями и результатом проверки.
