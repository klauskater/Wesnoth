# Контракт lua/time

Статус: **целевой, не реализован**. Редакция проекта: 1.
Поставщик: `scripts/game/rules/time.lua`.
[Карточка модуля](../../../../design/architecture/modules/lua/time.md).
Обязательны [общие соглашения](../../common.md) и [поток сообщений](../../stream.md).

## Назначение

Игровой календарь и влияние времени суток.

## Потребители и зависимости

Потребители: [lua/combat](../lua/combat.md), [lua/turns](../lua/turns.md), [lua/map](../lua/map.md), [lua/hud](../lua/hud.md).

Использует контракты: [lua/units](../lua/units.md), [engine/store](../engine/store.md).
Ссылка Lua → engine означает возможность host API через ctx, а не импорт Rust из Lua.
Обратная ссылка потребителя не разрешает обратный вызов или циклический импорт.

## Операции: вход → выход

```text
phase(read) -> Phase
advance(tx) -> DomainEvents
alignment_modifier(alignment,phase) -> Number
illumination_modifier(read,unit,phase) -> Number
```

Это обязательные логические формы, не готовые Rust-сигнатуры. Общие типы определены
в common.md; специфичные типы текущей игры используют её сохранённую семантику,
описанную в [таблице соответствия](../../README.md#прежние-документы).
Конкретный wire layout и имена полей этих игровых записей уточняются в данном
контракте до переключения вызывающих, а не скрыто внутри реализации.

## Гарантии и результат

Текущая фаза хранится в store; длина цикла и бонусы принадлежат пакету. Advance вызывается turns в заданной точке.

## Ошибки и побочные эффекты

Неизвестная конфигурация цикла -> Error. Не возвращает UI-виджеты; preview и бой получают одинаковые модификаторы.

## Владение данными

Цикл суток и правила модификаторов; текущая фаза в store.

## Что не входит в контракт

Не выбирает UI-картинку и не перекрашивает карту; presentation использует рассчитанную фазу.

## Приёмка реализации

Смена фазы одинаково влияет на прогноз и бой; порядок advance задаёт turns.

Перенос из: phase/alignment_modifier/illuminated_lawful_bonus в basic_combat.lua.
При внедрении добавить ссылку `Контракт: contracts/target/modules/lua/time.md`
в заголовок файла поставщика. Статус меняется на «реализован» только вместе
с реализацией, переведёнными потребителями и результатом проверки.
