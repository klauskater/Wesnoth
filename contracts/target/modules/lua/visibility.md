# Контракт lua/visibility

Статус: **целевой, не реализован**. Редакция проекта: 1.
Поставщик: `scripts/game/rules/visibility.lua`.
[Карточка модуля](../../../../design/architecture/modules/lua/visibility.md).
Обязательны [общие соглашения](../../common.md) и [поток сообщений](../../stream.md).

## Назначение

Обзор, туман, исследованность и скрытые объекты.

## Потребители и зависимости

Потребители: [lua/flow](../lua/flow.md), [lua/ai](../lua/ai.md), [lua/presenter](../lua/presenter.md), [lua/interaction](../lua/interaction.md), [lua/map](../lua/map.md), [lua/effects](../lua/effects.md).

Использует контракты: [lua/movement](../lua/movement.md), [lua/sides](../lua/sides.md), [lua/units](../lua/units.md), [lua/terrain](../lua/terrain.md), [engine/store](../engine/store.md).
Ссылка Lua → engine означает возможность host API через ctx, а не импорт Rust из Lua.
Обратная ссылка потребителя не разрешает обратный вызов или циклический импорт.

## Операции: вход → выход

```text
update_exploration(tx) -> DomainEvents
visible_cells(read,viewer) -> CellSet
visible_objects(read,viewer) -> ObjectIdSet
```

Это обязательные логические формы, не готовые Rust-сигнатуры. Общие типы определены
в common.md; специфичные типы текущей игры используют её сохранённую семантику,
описанную в [таблице соответствия](../../README.md#прежние-документы).
Конкретный wire layout и имена полей этих игровых записей уточняются в данном
контракте до переключения вызывающих, а не скрыто внутри реализации.

## Гарантии и результат

История исследования изменяется только update_exploration внутри команд. Viewer определяется сессией; кеш разделён по нему и revision.

## Ошибки и побочные эффекты

Неизвестный viewer -> Error, не полный обзор. Запросы read-only; данные невидимого объекта не выдаются через вспомогательные поля.

## Владение данными

История исследования в store; вычисляемый обзор — кеш по ревизии и наблюдателю.

## Что не входит в контракт

present только читает; исследование обновляется командой. Данные скрытых объектов не попадают в scene, UI, hit ids или effects.

## Приёмка реализации

Смена наблюдателя не использует чужой кеш; скрытый враг отсутствует во всём клиентском пакете.

Перенос из: visibility/hidden_from/update_shroud/can_see в basic_combat.lua.
При внедрении добавить ссылку `Контракт: contracts/target/modules/lua/visibility.md`
в заголовок файла поставщика. Статус меняется на «реализован» только вместе
с реализацией, переведёнными потребителями и результатом проверки.
