# Контракт lua/combat

Статус: **целевой, не реализован**. Редакция проекта: 1.
Поставщик: `scripts/game/rules/combat.lua`.
[Карточка модуля](../../../../design/architecture/modules/lua/combat.md).
Обязательны [общие соглашения](../../common.md) и [поток сообщений](../../stream.md).

## Назначение

Разрешение боя и общие для выполнения/прогноза боевые расчёты.

## Потребители и зависимости

Потребители: [lua/flow](../lua/flow.md), [lua/forecast](../lua/forecast.md), [lua/ai](../lua/ai.md), [lua/interaction](../lua/interaction.md), [lua/hud](../lua/hud.md).

Использует контракты: [lua/units](../lua/units.md), [lua/sides](../lua/sides.md), [lua/terrain](../lua/terrain.md), [lua/time](../lua/time.md), [engine/store](../engine/store.md).
Ссылка Lua → engine означает возможность host API через ctx, а не импорт Rust из Lua.
Обратная ссылка потребителя не разрешает обратный вызов или циклический импорт.

## Операции: вход → выход

```text
prepare(read,{attacker,defender,weapon}) -> PreparedBattle
legal_attacks(read,attacker) -> AttackOption[]
step(battle_state,strike,outcome) -> BattleStep
resolve(tx,request) -> DomainEvents
```

Это обязательные логические формы, не готовые Rust-сигнатуры. Общие типы определены
в common.md; специфичные типы текущей игры используют её сохранённую семантику,
описанную в [таблице соответствия](../../README.md#прежние-документы).
Конкретный wire layout и имена полей этих игровых записей уточняются в данном
контракте до переключения вызывающих, а не скрыто внутри реализации.

## Гарантии и результат

Step чистый, outcome задаёт попадание/промах; включает общие формулы урона/статусов/лечения. Resolve использует tx RNG. PreparedBattle не даёт права выполнить устаревшую атаку без проверки.

## Ошибки и побочные эффекты

Недопустимая атака -> Error; resolve не завершает сценарий и не рисует эффекты. Смерть/попадание возвращаются flow для следующих последствий.

## Владение данными

Боевые формулы и порядок ударов; записи результата через tx, случайность через tx RNG.

## Что не входит в контракт

Не рисует анимации и не завершает сценарий. Смерть и попадания возвращает в flow. Не зависит от forecast.

## Приёмка реализации

Фиксированная последовательность RNG воспроизводит бой; сценарные последствия выполняются flow.

Перенос из: basic_combat prepare_battle/strike/resolve; src/combat.rs impact.
При внедрении добавить ссылку `Контракт: contracts/target/modules/lua/combat.md`
в заголовок файла поставщика. Статус меняется на «реализован» только вместе
с реализацией, переведёнными потребителями и результатом проверки.
