# Контракт lua/campaign

Статус: **целевой, не реализован**. Редакция проекта: 1.
Поставщик: `scripts/game/campaign.lua`.
[Карточка модуля](../../../../design/architecture/modules/lua/campaign.md).
Обязательны [общие соглашения](../../common.md) и [поток сообщений](../../stream.md).

## Назначение

Каталог приключений и правила перехода между сценариями.

## Потребители и зависимости

Потребители: [lua/bootstrap](../lua/bootstrap.md), [lua/flow](../lua/flow.md), [lua/hud](../lua/hud.md).

Использует контракты: [lua/units](../lua/units.md), [lua/sides](../lua/sides.md), [engine/resources](../engine/resources.md), [engine/store](../engine/store.md).
Ссылка Lua → engine означает возможность host API через ctx, а не импорт Rust из Lua.
Обратная ссылка потребителя не разрешает обратный вызов или циклический импорт.

## Операции: вход → выход

```text
catalog(resources) -> Adventure[]
carryover(read,result) -> Carryover
next_scenario(read,result) -> Optional<ScenarioId>
transition_data(read,result) -> Transition
```

Это обязательные логические формы, не готовые Rust-сигнатуры. Общие типы определены
в common.md; специфичные типы текущей игры используют её сохранённую семантику,
описанную в [таблице соответствия](../../README.md#прежние-документы).
Конкретный wire layout и имена полей этих игровых записей уточняются в данном
контракте до переключения вызывающих, а не скрыто внутри реализации.

## Гарантии и результат

Transition = next scenario + carryover; применение через flow/bootstrap. Catalog — игровые данные для HUD; перенос детерминирован, без изменения исходной главы в query.

## Ошибки и побочные эффекты

Неизвестная глава/некорректные связи -> Error; отсутствие следующей главы — нормальный конец кампании. Запрос не выполняет перенос повторно.

## Владение данными

Прогресс кампании, переносимые units/gold/variables в store.

## Что не входит в контракт

Не читает файловую систему напрямую и не открывает клиентские экраны. Загрузка следующей главы проходит bootstrap через flow.

## Приёмка реализации

Переход переносит ровно разрешённые данные; загрузка сохранения не повторяет перенос.

Перенос из: src/adventure.rs; CampaignState/campaign_state/next_scenario в src/game.rs.
При внедрении добавить ссылку `Контракт: contracts/target/modules/lua/campaign.md`
в заголовок файла поставщика. Статус меняется на «реализован» только вместе
с реализацией, переведёнными потребителями и результатом проверки.
