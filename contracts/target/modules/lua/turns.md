# Контракт lua/turns

Статус: **целевой, не реализован**. Редакция проекта: 1.
Поставщик: `scripts/game/rules/turns.lua`.
[Карточка модуля](../../../../design/architecture/modules/lua/turns.md).
Обязательны [общие соглашения](../../common.md) и [поток сообщений](../../stream.md).

## Назначение

Очередность ходов и процедуры их начала/окончания.

## Потребители и зависимости

Потребители: [lua/flow](../lua/flow.md).

Использует контракты: [lua/sides](../lua/sides.md), [lua/time](../lua/time.md), [lua/economy](../lua/economy.md), [lua/units](../lua/units.md), [lua/terrain](../lua/terrain.md), [engine/store](../engine/store.md).
Ссылка Lua → engine означает возможность host API через ctx, а не импорт Rust из Lua.
Обратная ссылка потребителя не разрешает обратный вызов или циклический импорт.

## Операции: вход → выход

```text
end_side(tx,side) -> DomainEvents
next_side(read) -> SideId
begin_side(tx,side) -> DomainEvents
```

Это обязательные логические формы, не готовые Rust-сигнатуры. Общие типы определены
в common.md; специфичные типы текущей игры используют её сохранённую семантику,
описанную в [таблице соответствия](../../README.md#прежние-документы).
Конкретный wire layout и имена полей этих игровых записей уточняются в данном
контракте до переключения вызывающих, а не скрыто внутри реализации.

## Гарантии и результат

End/begin вызываются flow ровно один раз в установленном порядке; лечение, доход, MP и временные статусы применяются здесь через нижние rules.

## Ошибки и побочные эффекты

Несоответствие активной стороны -> Error. Не запускает бесконечный AI-цикл; сценарные триггеры возвращаются flow как факты.

## Владение данными

Номер хода и активная сторона в store; порядок локальных процедур хода.

## Что не входит в контракт

Не запускает полный AI-ход и не обрабатывает сценарные триггеры; возвращает события flow.

## Приёмка реализации

Доход, лечение, истечение статусов и переход суток происходят ровно один раз в нужной фазе.

Перенос из: reset_side/start_side/finish_side/end_turn в basic_combat.lua.
При внедрении добавить ссылку `Контракт: contracts/target/modules/lua/turns.md`
в заголовок файла поставщика. Статус меняется на «реализован» только вместе
с реализацией, переведёнными потребителями и результатом проверки.
