# Контракт lua/scenario

Статус: **целевой, не реализован**. Редакция проекта: 1.
Поставщик: `scripts/game/scenario.lua`.
[Карточка модуля](../../../../design/architecture/modules/lua/scenario.md).
Обязательны [общие соглашения](../../common.md) и [поток сообщений](../../stream.md).

## Назначение

Сценарные триггеры, цели, диалоги и обязательные выборы.

## Потребители и зависимости

Потребители: [lua/bootstrap](../lua/bootstrap.md), [lua/flow](../lua/flow.md), [lua/hud](../lua/hud.md).

Использует контракты: [lua/units](../lua/units.md), [lua/sides](../lua/sides.md), [lua/terrain](../lua/terrain.md), [engine/store](../engine/store.md).
Ссылка Lua → engine означает возможность host API через ctx, а не импорт Rust из Lua.
Обратная ссылка потребителя не разрешает обратный вызов или циклический импорт.

## Операции: вход → выход

```text
initialize(tx,scenario) -> DomainEvents
on_events(tx,events) -> {events,followups}
choose(tx,choice_id) -> DomainEvents
acknowledge(tx,dialog_id) -> DomainEvents
```

Это обязательные логические формы, не готовые Rust-сигнатуры. Общие типы определены
в common.md; специфичные типы текущей игры используют её сохранённую семантику,
описанную в [таблице соответствия](../../README.md#прежние-документы).
Конкретный wire layout и имена полей этих игровых записей уточняются в данном
контракте до переключения вызывающих, а не скрыто внутри реализации.

## Гарантии и результат

Хранит обработанные триггеры, pending choice/dialog и цели в store. Followups — ограниченный список действий для flow; результат не открывает клиентский экран напрямую.

## Ошибки и побочные эффекты

Уже обработанный trigger не повторяет последствия; неподходящий choice/dialog -> Error. Не импортирует и не вызывает flow рекурсивно.

## Владение данными

Переменные сценария, обработанные триггеры, pending choice/dialog, результат в store.

## Что не входит в контракт

Не вызывает flow рекурсивно: возвращает follow-up действия. Не выбирает клиентский экран напрямую.

## Приёмка реализации

Событие не срабатывает повторно после сохранения; обязательный выбор блокирует неподходящие команды.

Перенос из: objective_event/turn_event/location_event/choose; DialogLine/pending_dialog в game.rs.
При внедрении добавить ссылку `Контракт: contracts/target/modules/lua/scenario.md`
в заголовок файла поставщика. Статус меняется на «реализован» только вместе
с реализацией, переведёнными потребителями и результатом проверки.
