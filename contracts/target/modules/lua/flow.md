# Контракт lua/flow

Статус: **целевой, не реализован**. Редакция проекта: 1.
Поставщик: `scripts/game/flow.lua`.
[Карточка модуля](../../../../design/architecture/modules/lua/flow.md).
Обязательны [общие соглашения](../../common.md) и [поток сообщений](../../stream.md).

## Назначение

Порядок выполнения одной игровой команды и связанных последствий.

## Потребители и зависимости

Потребители: [lua/entry](../lua/entry.md).

Использует контракты: [lua/units](../lua/units.md), [lua/sides](../lua/sides.md), [lua/terrain](../lua/terrain.md), [lua/movement](../lua/movement.md), [lua/combat](../lua/combat.md), [lua/turns](../lua/turns.md), [lua/economy](../lua/economy.md), [lua/visibility](../lua/visibility.md), [lua/scenario](../lua/scenario.md), [lua/campaign](../lua/campaign.md), [lua/ai](../lua/ai.md), [engine/store](../engine/store.md).
Ссылка Lua → engine означает возможность host API через ctx, а не импорт Rust из Lua.
Обратная ссылка потребителя не разрешает обратный вызов или циклический импорт.

## Операции: вход → выход

```text
dispatch(tx, {action,payload,actor}) -> DomainEvents
```

Это обязательные логические формы, не готовые Rust-сигнатуры. Общие типы определены
в common.md; специфичные типы текущей игры используют её сохранённую семантику,
описанную в [таблице соответствия](../../README.md#прежние-документы).
Конкретный wire layout и имена полей этих игровых записей уточняются в данном
контракте до переключения вызывающих, а не скрыто внутри реализации.

## Гарантии и результат

Проверяет общие блокировки; вызывает rule; применяет последствия, XP, цели и видимость до устойчивого состояния/обязательного выбора. Команды человека и AI идут одним путём.

## Ошибки и побочные эффекты

Неизвестное действие, неверная сторона/фаза/выбор -> Error и rollback. Цикл последствий имеет лимит; вложенный commit запрещён.

## Владение данными

Маршрутизация команд и явно заданный порядок обработки; временная очередь событий внутри транзакции.

## Что не входит в контракт

Нижние rules не импортируют flow. Нет глобальной шины подписок. Цепочка ограничена, зацикливание прерывает транзакцию.

## Приёмка реализации

Смерть, XP, обязательный выбор и завершение сценария имеют проверенный порядок и единый rollback.

Перенос из: basic_combat.resolve/move/end_turn/choose; оркестрация Game::execute.
При внедрении добавить ссылку `Контракт: contracts/target/modules/lua/flow.md`
в заголовок файла поставщика. Статус меняется на «реализован» только вместе
с реализацией, переведёнными потребителями и результатом проверки.
