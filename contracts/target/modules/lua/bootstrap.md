# Контракт lua/bootstrap

Статус: **целевой, не реализован**. Редакция проекта: 1.
Поставщик: `scripts/game/bootstrap.lua`.
[Карточка модуля](../../../../design/architecture/modules/lua/bootstrap.md).
Обязательны [общие соглашения](../../common.md) и [поток сообщений](../../stream.md).

## Назначение

Преобразование декларативных данных именно этой игры в начальный мир.

## Потребители и зависимости

Потребители: [lua/entry](../lua/entry.md).

Использует контракты: [lua/units](../lua/units.md), [lua/terrain](../lua/terrain.md), [lua/scenario](../lua/scenario.md), [lua/campaign](../lua/campaign.md), [engine/resources](../engine/resources.md), [engine/store](../engine/store.md).
Ссылка Lua → engine означает возможность host API через ctx, а не импорт Rust из Lua.
Обратная ссылка потребителя не разрешает обратный вызов или циклический импорт.

## Операции: вход → выход

```text
load_catalogs(resources) -> Catalogs
create_scenario(tx, scenario_id, carryover?) -> DomainEvents
validate_restored(read) -> Unit
```

Это обязательные логические формы, не готовые Rust-сигнатуры. Общие типы определены
в common.md; специфичные типы текущей игры используют её сохранённую семантику,
описанную в [таблице соответствия](../../README.md#прежние-документы).
Конкретный wire layout и имена полей этих игровых записей уточняются в данном
контракте до переключения вызывающих, а не скрыто внутри реализации.

## Гарантии и результат

Читает семантику WML и создаёт игровой мир пакетно. Инициализация применяется только к новому сценарию; каталоги read-only.

## Ошибки и побочные эффекты

Неизвестный тип, дублированный id, некорректный сценарий -> Error с rollback. Validate_restored не применяет traits и начальный доход повторно.

## Владение данными

Схема и начальные значения сценария/каталогов. Каталоги неизменяемы и доступны отдельно от mutable state.

## Что не входит в контракт

Не рисует интерфейс. Парсинг синтаксиса остаётся в Rust; толкование тегов здесь.

## Приёмка реализации

Расы, traits, деревни и стартовое золото определяются без знания этих слов в Rust.

Перенос из: Game::load_with_campaign_from; basic_combat.initialize.
При внедрении добавить ссылку `Контракт: contracts/target/modules/lua/bootstrap.md`
в заголовок файла поставщика. Статус меняется на «реализован» только вместе
с реализацией, переведёнными потребителями и результатом проверки.
