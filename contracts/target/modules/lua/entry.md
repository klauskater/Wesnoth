# Контракт lua/entry

Статус: **частично реализован**. Редакция проекта: 1. Все четыре входа и модульные
require подключены; dispatch пока делегирует монолитному rules.basic_combat.
Поставщик: `scripts/game/init.lua`.
[Карточка модуля](../../../../design/architecture/modules/lua/entry.md).
Обязательны [общие соглашения](../../common.md) и [поток сообщений](../../stream.md).

## Назначение

Единственная внешняя точка входа пакета и явная сборка модулей.

## Потребители и зависимости

Потребители: [engine/runtime](../engine/runtime.md).

Использует контракты: [lua/bootstrap](../lua/bootstrap.md), [lua/flow](../lua/flow.md), [lua/presenter](../lua/presenter.md), [lua/interaction](../lua/interaction.md).
Ссылка Lua → engine означает возможность host API через ctx, а не импорт Rust из Lua.
Обратная ссылка потребителя не разрешает обратный вызов или циклический импорт.

## Операции: вход → выход

```text
initialize(tx, request) -> Unit
dispatch(tx, command) -> DomainEvents
present(read, viewer, view_context, changes, events) -> Presentation
interact(read,viewer,view_context,input) -> InteractionResult
```

Это обязательные логические формы, не готовые Rust-сигнатуры. Общие типы определены
в common.md; специфичные типы текущей игры используют её сохранённую семантику,
описанную в [таблице соответствия](../../README.md#прежние-документы).
Конкретный wire layout и имена полей этих игровых записей уточняются в данном
контракте до переключения вызывающих, а не скрыто внутри реализации.

## Гарантии и результат

Четыре внешних входа пакета: initialize → bootstrap, dispatch → flow, present → presenter, interact → presentation/interaction. Вызовы нижних модулей остаются в VM.

## Ошибки и побочные эффекты

Неверная входная форма/неизвестная команда -> Error. Экспорты не хранят изменяемый мир в globals/upvalues.

## Владение данными

Таблица экспортов и ссылки на модули; авторитетного состояния в upvalues нет.

## Что не входит в контракт

Не содержит формул боя или вёрстки; не склеивает файлы текстом. Модули возвращают локальные таблицы через контролируемый require.

## Приёмка реализации

Внешняя граница остаётся одинаковой при замене пакета.

Перенос из: return combat и общая таблица basic_combat.lua; склейка rules в game.rs.
При внедрении добавить ссылку `Контракт: contracts/target/modules/lua/entry.md`
в заголовок файла поставщика. Статус меняется на «реализован» только вместе
с реализацией, переведёнными потребителями и результатом проверки.
