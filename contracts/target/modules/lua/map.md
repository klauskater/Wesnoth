# Контракт lua/map

Статус: **целевой, не реализован**. Редакция проекта: 1.
Поставщик: `scripts/game/presentation/map.lua`.
[Карточка модуля](../../../../design/architecture/modules/lua/map.md).
Обязательны [общие соглашения](../../common.md) и [поток сообщений](../../stream.md).

## Назначение

Подготовка всей видимой сцены гекс-поля.

## Потребители и зависимости

Потребители: [lua/presenter](../lua/presenter.md).

Использует контракты: [lua/terrain_rendering](../lua/terrain_rendering.md), [lua/visibility](../lua/visibility.md), [lua/time](../lua/time.md), [lua/movement](../lua/movement.md), [lua/units](../lua/units.md).
Ссылка Lua → engine означает возможность host API через ctx, а не импорт Rust из Lua.
Обратная ссылка потребителя не разрешает обратный вызов или циклический импорт.

## Операции: вход → выход

```text
build(read,viewer,view_context) -> SceneBlocks
update(read,viewer,view_context,changes) -> BlockChanges
```

Это обязательные логические формы, не готовые Rust-сигнатуры. Общие типы определены
в common.md; специфичные типы текущей игры используют её сохранённую семантику,
описанную в [таблице соответствия](../../README.md#прежние-документы).
Конкретный wire layout и имена полей этих игровых записей уточняются в данном
контракте до переключения вызывающих, а не скрыто внутри реализации.

## Гарантии и результат

Только видимые terrain, units, флаги, подсветки и миникарта; стабильные ids; соседние переходы входят в область invalidation.

## Ошибки и побочные эффекты

Неподдерживаемый asset/ошибка семейства -> Error; не отдаёт сырые скрытые объекты клиенту. View не записывает исследованность.

## Владение данными

Визуальные соглашения игры; стабильные ids объектов сцены и кеши участков.

## Что не входит в контракт

Не выполняет GPU-вызовы. Не передаёт скрытые игровые данные для последующей фильтрации клиентом.

## Приёмка реализации

Сцена полностью определяет отображение и обновляется без запросов к Lua на кадр.

Перенос из: src/map.rs/terrain_rules.rs игровая часть; village_renderer.rs; unit drawing screens/game.rs.
При внедрении добавить ссылку `Контракт: contracts/target/modules/lua/map.md`
в заголовок файла поставщика. Статус меняется на «реализован» только вместе
с реализацией, переведёнными потребителями и результатом проверки.
