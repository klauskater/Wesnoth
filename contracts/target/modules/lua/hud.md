# Контракт lua/hud

Статус: **частично реализован**. Редакция проекта: 1. HUD публикует типизированные
деревья UiNode с вычисленными label/enabled/action для завершения хода, а также
label/image/tooltip/map tint/scene variant времени суток, summary, панель юнита
меню найма/recall и постраничные диалоги с готовыми ценами/enabled/action; остальные панели и обязательные
выборы ещё переносятся из GameScreen.
Поставщик: `scripts/game/presentation/hud.lua`.
[Карточка модуля](../../../../design/architecture/modules/lua/hud.md).
Обязательны [общие соглашения](../../common.md) и [поток сообщений](../../stream.md).

## Назначение

Описание игрового интерфейса и игровых меню через общие UiNode.

## Потребители и зависимости

Потребители: [lua/presenter](../lua/presenter.md).

Использует контракты: [lua/time](../lua/time.md), [lua/units](../lua/units.md), [lua/economy](../lua/economy.md), [lua/combat](../lua/combat.md), [lua/forecast](../lua/forecast.md), [lua/sides](../lua/sides.md), [lua/scenario](../lua/scenario.md), [lua/campaign](../lua/campaign.md).
Ссылка Lua → engine означает возможность host API через ctx, а не импорт Rust из Lua.
Обратная ссылка потребителя не разрешает обратный вызов или циклический импорт.

## Операции: вход → выход

```text
build(read,viewer,view_context) -> UiBlocks
update(read,viewer,view_context,changes) -> BlockChanges
```

Это обязательные логические формы, не готовые Rust-сигнатуры. Общие типы определены
в common.md; специфичные типы текущей игры используют её сохранённую семантику,
описанную в [таблице соответствия](../../README.md#прежние-документы).
Конкретный wire layout и имена полей этих игровых записей уточняются в данном
контракте до переключения вызывающих, а не скрыто внутри реализации.

## Гарантии и результат

Тексты, картинки, прогресс и action вычисляются из rules; UI не содержит исполняемых Lua callback. Обязательный выбор отражает store, просмотр панели — view_context.

## Ошибки и побочные эффекты

Недоступный выбор/удалённый юнит даёт согласованное пустое/обновлённое представление; ошибка данных -> Error. Нет дублирования формул боя или цены.

## Владение данными

Тексты, assets, layout декларации и action payload; отдельные layout-ресурсы допустимы.

## Что не входит в контракт

Не задаёт игровые формулы, не принимает решение о допустимости команды вместо rules. Пока панели — локальные функции одного файла.

## Приёмка реализации

В Rust отсутствуют чтения time_of_day/hitpoints/gold для UI; конец хода — обычный action.

Перенос из: basic_combat.status/unit_option; time_info/time_tint и панели screens/game.rs; screens/adventures.rs.
При внедрении добавить ссылку `Контракт: contracts/target/modules/lua/hud.md`
в заголовок файла поставщика. Статус меняется на «реализован» только вместе
с реализацией, переведёнными потребителями и результатом проверки.
