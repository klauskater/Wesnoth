# Контракт lua/terrain

Статус: **целевой, не реализован**. Редакция проекта: 1.
Поставщик: `scripts/game/rules/terrain.lua`.
[Карточка модуля](../../../../design/architecture/modules/lua/terrain.md).
Обязательны [общие соглашения](../../common.md) и [поток сообщений](../../stream.md).

## Назначение

Игровая семантика местности этой игры.

## Потребители и зависимости

Потребители: [lua/bootstrap](../lua/bootstrap.md), [lua/flow](../lua/flow.md), [lua/movement](../lua/movement.md), [lua/combat](../lua/combat.md), [lua/turns](../lua/turns.md), [lua/economy](../lua/economy.md), [lua/visibility](../lua/visibility.md), [lua/scenario](../lua/scenario.md).

Использует контракты: [engine/resources](../engine/resources.md).
Ссылка Lua → engine означает возможность host API через ctx, а не импорт Rust из Lua.
Обратная ссылка потребителя не разрешает обратный вызов или циклический импорт.

## Операции: вход → выход

```text
decode_cell(raw_code) -> TerrainId
movement_cost(unit,terrain) -> Int
defense(unit,terrain) -> Number
is_village(terrain) -> Bool
is_recruitment_ground(terrain) -> Bool
```

Это обязательные логические формы, не готовые Rust-сигнатуры. Общие типы определены
в common.md; специфичные типы текущей игры используют её сохранённую семантику,
описанную в [таблице соответствия](../../README.md#прежние-документы).
Конкретный wire layout и имена полей этих игровых записей уточняются в данном
контракте до переключения вызывающих, а не скрыто внутри реализации.

## Гарантии и результат

Игровое значение кодов и поведение неизвестного кода сохраняются при миграции текущей игры; картинка не определяет стоимость движения.

## Ошибки и побочные эффекты

Неверные параметры -> Error; чистые запросы без записи и выбора спрайтов. Таблицы свойств принадлежат каталогу пакета.

## Владение данными

Значение кодов terrain и их игровых свойств.

## Что не входит в контракт

Не выбирает спрайты; визуальные семейства принадлежат presentation/terrain.

## Приёмка реализации

Новый код местности меняет движение и защиту через пакет, без Rust-ветвлений.

Перенос из: src/terrain.rs gameplay_type; src/map.rs игровые свойства; basic_combat terrain logic.
При внедрении добавить ссылку `Контракт: contracts/target/modules/lua/terrain.md`
в заголовок файла поставщика. Статус меняется на «реализован» только вместе
с реализацией, переведёнными потребителями и результатом проверки.
