# Контракт lua/effects

Статус: **частично реализован**. Редакция проекта: 1. Стабильные effect ids и
перевод domain events готовы; viewer visibility-фильтрация ещё не перенесена.
Поставщик: `scripts/game/presentation/effects.lua`.
[Карточка модуля](../../../../design/architecture/modules/lua/effects.md).
Обязательны [общие соглашения](../../common.md) и [поток сообщений](../../stream.md).

## Назначение

Перевод игровых событий в видимые одноразовые эффекты.

## Потребители и зависимости

Потребители: [lua/presenter](../lua/presenter.md).

Использует контракты: [lua/visibility](../lua/visibility.md), [engine/resources](../engine/resources.md).
Ссылка Lua → engine означает возможность host API через ctx, а не импорт Rust из Lua.
Обратная ссылка потребителя не разрешает обратный вызов или циклический импорт.

## Операции: вход → выход

```text
translate(events,visibility_before,visibility_after,command_id,viewer) -> Effect[]
```

Это обязательные логические формы, не готовые Rust-сигнатуры. Общие типы определены
в common.md; специфичные типы текущей игры используют её сохранённую семантику,
описанную в [таблице соответствия](../../README.md#прежние-документы).
Конкретный wire layout и имена полей этих игровых записей уточняются в данном
контракте до переключения вызывающих, а не скрыто внутри реализации.

## Гарантии и результат

Общие эффекты кадров/траекторий/звука с id(command_id,index,viewer). Порядок стабилен; политика раскрытия определяется видимостью события и участников.

## Ошибки и побочные эффекты

Нет разрешённого представления скрытого события -> эффект пропускается, не раскрывая позицию/звук. Повторный вызов не меняет мир и не создаёт новые ids.

## Владение данными

Визуальный язык игры; effects связаны с committed command id и индексом.

## Что не входит в контракт

Не меняет HP и не рассчитывает бой. Скрытый бой не раскрывается через звук/координаты; политика видимости явно задана игрой.

## Приёмка реализации

Повторный present не создаёт новые ids для тех же эффектов; сохранение не повторяет уже прошедшую анимацию.

Перенос из: client/battle.rs, movement.rs; трактовка domain events клиентом.
При внедрении добавить ссылку `Контракт: contracts/target/modules/lua/effects.md`
в заголовок файла поставщика. Статус меняется на «реализован» только вместе
с реализацией, переведёнными потребителями и результатом проверки.
