# Контракт lua/interaction

Статус: **частично реализован**. Редакция проекта: 1. Viewer context и обычные
action-команды проходят через Session; игровая трактовка выбора/клеток ещё в клиенте.
Поставщик: `scripts/game/presentation/interaction.lua`.
[Карточка модуля](../../../../design/architecture/modules/lua/interaction.md).
Обязательны [общие соглашения](../../common.md) и [поток сообщений](../../stream.md).

## Назначение

Игровое значение кликов и контекст просмотра.

## Потребители и зависимости

Потребители: [lua/entry](../lua/entry.md).

Использует контракты: [lua/movement](../lua/movement.md), [lua/combat](../lua/combat.md), [lua/economy](../lua/economy.md), [lua/visibility](../lua/visibility.md), [lua/sides](../lua/sides.md).
Ссылка Lua → engine означает возможность host API через ctx, а не импорт Rust из Lua.
Обратная ссылка потребителя не разрешает обратный вызов или циклический импорт.

## Операции: вход → выход

```text
interpret(read,viewer,view_context,input) -> {view_context,command?}
```

Это обязательные логические формы, не готовые Rust-сигнатуры. Общие типы определены
в common.md; специфичные типы текущей игры используют её сохранённую семантику,
описанную в [таблице соответствия](../../README.md#прежние-документы).
Конкретный wire layout и имена полей этих игровых записей уточняются в данном
контракте до переключения вызывающих, а не скрыто внутри реализации.

## Гарантии и результат

Контекст содержит выбор/hover/просматриваемую панель. Runtime вызывает entry.interact; его результат — новый контекст и необязательная command, которую session передаёт обычному dispatch. Present не создаёт команды.

## Ошибки и побочные эффекты

Устаревшая view revision проверяется session; скрытая/исчезнувшая цель не становится действием. Не пишет мир. Повтор взаимодействия не должен создавать команду с новым command_id.

## Владение данными

Схема selected/hovered/modal контекста конкретного наблюдателя; хранит его session отдельно от мира.

## Что не входит в контракт

Не применяет игровую command непосредственно и не решает координаты пикселей. Команда возвращается в session и проходит dispatch.

## Приёмка реализации

Тот же клик в другой игре может значить другое без правки клиента; скрытый объект нельзя выбрать по id.

Перенос из: логика выбора/движения/атаки screens/game.rs; basic_combat.actions.
При внедрении добавить ссылку `Контракт: contracts/target/modules/lua/interaction.md`
в заголовок файла поставщика. Статус меняется на «реализован» только вместе
с реализацией, переведёнными потребителями и результатом проверки.
