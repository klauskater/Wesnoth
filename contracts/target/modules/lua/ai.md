# Контракт lua/ai

Статус: **целевой, не реализован**. Редакция проекта: 1.
Поставщик: `scripts/game/ai.lua`.
[Карточка модуля](../../../../design/architecture/modules/lua/ai.md).
Обязательны [общие соглашения](../../common.md) и [поток сообщений](../../stream.md).

## Назначение

Выбор допустимых команд для компьютерной стороны.

## Потребители и зависимости

Потребители: [lua/flow](../lua/flow.md).

Использует контракты: [lua/movement](../lua/movement.md), [lua/combat](../lua/combat.md), [lua/forecast](../lua/forecast.md), [lua/economy](../lua/economy.md), [lua/visibility](../lua/visibility.md), [lua/sides](../lua/sides.md).
Ссылка Lua → engine означает возможность host API через ctx, а не импорт Rust из Lua.
Обратная ссылка потребителя не разрешает обратный вызов или циклический импорт.

## Операции: вход → выход

```text
next_command(read,side,budget) -> Command | Done | Yield
```

Это обязательные логические формы, не готовые Rust-сигнатуры. Общие типы определены
в common.md; специфичные типы текущей игры используют её сохранённую семантику,
описанную в [таблице соответствия](../../README.md#прежние-документы).
Конкретный wire layout и имена полей этих игровых записей уточняются в данном
контракте до переключения вызывающих, а не скрыто внутри реализации.

## Гарантии и результат

Использует только разрешённое стороне знание и общие rules/forecast. Yield означает продолжение планирования, Done — отсутствие автоматической работы; закончить ход — обычная Command.

## Ошибки и побочные эффекты

Превышение бюджета -> Yield без частичного действия. Возвращённая command не считается допустимой до flow.dispatch; кеш сбрасываем.

## Владение данными

Эвристики и сбрасываемые кеши; продолжительный план, если нужен для сохранений, хранится в store.

## Что не входит в контракт

Не пишет мир в обход dispatch. Использует разрешённое стороне знание. Не исполняет весь ход неограниченным блокирующим циклом.

## Приёмка реализации

Команды AI проходят те же проверки, что человеческие; планирование ограничено бюджетом и продолжимо.

Перенос из: scripts/rules/simple_ai.lua.
При внедрении добавить ссылку `Контракт: contracts/target/modules/lua/ai.md`
в заголовок файла поставщика. Статус меняется на «реализован» только вместе
с реализацией, переведёнными потребителями и результатом проверки.
