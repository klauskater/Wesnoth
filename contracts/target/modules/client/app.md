# Контракт client/app

Статус: **целевой, не реализован**. Редакция проекта: 1.
Поставщик: `src/bin/client/app.rs`.
[Карточка модуля](../../../../design/architecture/modules/client/app.md).
Обязательны [общие соглашения](../../common.md) и [поток сообщений](../../stream.md).

## Назначение

Запуск платформенного клиента и соединение его частей.

## Потребители и зависимости

Потребители: точка запуска приложения / внешний вызывающий.

Использует контракты: [client/connection](../client/connection.md), [client/view](../client/view.md), [client/input](../client/input.md), [client/ui](../client/ui.md), [client/scene](../client/scene.md), [client/viewport](../client/viewport.md), [client/effects](../client/effects.md).
Ссылка Lua → engine означает возможность host API через ctx, а не импорт Rust из Lua.
Обратная ссылка потребителя не разрешает обратный вызов или циклический импорт.

## Операции: вход → выход

```text
start(package_selection, settings) -> App
frame(input, elapsed) -> Unit
close() -> Unit
```

Это обязательные логические формы, не готовые Rust-сигнатуры. Общие типы определены
в common.md; специфичные типы текущей игры используют её сохранённую семантику,
описанную в [таблице соответствия](../../README.md#прежние-документы).
Конкретный wire layout и имена полей этих игровых записей уточняются в данном
контракте до переключения вызывающих, а не скрыто внутри реализации.

## Гарантии и результат

Владеет окном и сборкой клиента. Игровые меню приходят из пакета; локальные системные настройки не являются игровыми командами.

## Ошибки и побочные эффекты

Ошибка загрузки/подключения показывается как техническая ошибка; цикл frame сам по себе не вызывает игровые правила.

## Владение данными

Окно и жизненный цикл клиента.

## Что не входит в контракт

Не выбирает следующую главу кампании и не определяет каталог игровых приключений. Его содержимое приходит из пакета.

## Приёмка реализации

После смены пакета меняются игровые меню и правила без ветвления по package id в клиенте.

Перенос из: src/bin/client.rs; screens/main_menu.rs; screens/adventures.rs.
При внедрении добавить ссылку `Контракт: contracts/target/modules/client/app.md`
в заголовок файла поставщика. Статус меняется на «реализован» только вместе
с реализацией, переведёнными потребителями и результатом проверки.
