# Контракт client/scene

Статус: **частично реализован**. Редакция проекта: 1. SceneItem ground/world
приходит из View, сортируется по явным order/id, валидируется и готовится вместе
с frames/tint/crop/masks/opacity; неизменный draw не обращается к Lua/session.
Юниты, деревни, hit regions и minimap ещё используют прежние потребители.
Поставщик: `src/bin/client/scene.rs`.
[Карточка модуля](../../../../design/architecture/modules/client/scene.md).
Обязательны [общие соглашения](../../common.md) и [поток сообщений](../../stream.md).

## Назначение

Рисование готовой сцены и загрузка её графических ресурсов.

## Потребители и зависимости

Потребители: [client/app](../client/app.md), [client/effects](../client/effects.md).

Использует контракты: [client/view](../client/view.md), [client/viewport](../client/viewport.md), [engine/protocol](../engine/protocol.md).
Ссылка Lua → engine означает возможность host API через ctx, а не импорт Rust из Lua.
Обратная ссылка потребителя не разрешает обратный вызов или циклический импорт.

## Операции: вход → выход

```text
prepare(SceneBlocks, assets) -> RenderScene
draw(RenderScene, camera, elapsed) -> HitRegions
```

Это обязательные логические формы, не готовые Rust-сигнатуры. Общие типы определены
в common.md; специфичные типы текущей игры используют её сохранённую семантику,
описанную в [таблице соответствия](../../README.md#прежние-документы).
Конкретный wire layout и имена полей этих игровых записей уточняются в данном
контракте до переключения вызывающих, а не скрыто внутри реализации.

## Гарантии и результат

Принимает готовые слои/спрайты/tint/кадры и слой миникарты; упорядочивает по явным ключам, не по названию terrain.

## Ошибки и побочные эффекты

Неизвестный asset/нулевая длительность кадра -> Error до установки сцены. Неизменный draw не читает session или Lua.

## Владение данными

GPU-ресурсы, кеш текстур и буферы отрисовки.

## Что не входит в контракт

Не определяет варианты terrain, флаги деревень, видимость врагов или время суток.

## Приёмка реализации

При неизменном представлении кадр не обращается к движку или Lua; скрытые данные не нужны для миникарты.

Перенос из: map_renderer.rs, sprite_renderer.rs, village_renderer.rs.
При внедрении добавить ссылку `Контракт: contracts/target/modules/client/scene.md`
в заголовок файла поставщика. Статус меняется на «реализован» только вместе
с реализацией, переведёнными потребителями и результатом проверки.
