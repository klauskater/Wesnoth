# Контракт client/connection

Статус: **частично реализован**. Редакция проекта: 1. Встроенный адаптер хранит
корреляцию и ревизии, сохраняет порядок CommandResult/ViewUpdate/Error и выдаёт
snapshot; основной командный путь GameScreen, movement/battle reads и проверки
ревизии переведены. Осталось перевести жесты на Interaction и убрать чтение
сценарной карты/диалогов через Game из клиента.
Поставщик: `src/bin/client/connection.rs`.
[Карточка модуля](../../../../design/architecture/modules/client/connection.md).
Обязательны [общие соглашения](../../common.md) и [поток сообщений](../../stream.md).

## Назначение

Адаптация вызовов встроенной сессии к протоколу клиента.

## Потребители и зависимости

Потребители: [client/app](../client/app.md).

Использует контракты: [engine/session](../engine/session.md), [engine/protocol](../engine/protocol.md).
Ссылка Lua → engine означает возможность host API через ctx, а не импорт Rust из Lua.
Обратная ссылка потребителя не разрешает обратный вызов или циклический импорт.

## Операции: вход → выход

```text
send_command(Command) -> RequestId
send_interaction(Interaction) -> RequestId
receive() -> Delivery[]
request_snapshot() -> Unit
```

Это обязательные логические формы, не готовые Rust-сигнатуры. Общие типы определены
в common.md; специфичные типы текущей игры используют её сохранённую семантику,
описанную в [таблице соответствия](../../README.md#прежние-документы).
Конкретный wire layout и имена полей этих игровых записей уточняются в данном
контракте до переключения вызывающих, а не скрыто внутри реализации.

## Гарантии и результат

Единственная точка доступа игрового клиента к session. Delivery = CommandResult | ViewSnapshot | ViewUpdate | Error; порядок сообщений сохраняется.

## Ошибки и побочные эффекты

Ошибка транспорта/сессии не означает отказ уже committed команды; разрешение неопределённости — по command_id/snapshot, не повтор с новым id.

## Владение данными

Состояние подключения, корреляция ответов и ожидаемые ревизии.

## Что не входит в контракт

Не вызывает именованные внутренние Lua-функции; не читает World. Сетевой транспорт сейчас не реализуется.

## Приёмка реализации

Весь доступ клиента к сессии проходит через этот файл.

Перенос из: прямые вызовы Game в screens/game.rs.
При внедрении добавить ссылку `Контракт: contracts/target/modules/client/connection.md`
в заголовок файла поставщика. Статус меняется на «реализован» только вместе
с реализацией, переведёнными потребителями и результатом проверки.
