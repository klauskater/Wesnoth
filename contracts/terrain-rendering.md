# Контракт отрисовки ландшафта

Специфика семейства тайлов не принадлежит клиенту. Компиляторы семейств
формируют `TerrainScene` один раз при загрузке сценария. Клиент получает только
реестр графических ресурсов и список `PlacedSprite`.

`PlacedSprite` содержит семейство, гекс-якорь, смещение в пикселях относительно
центра эталонного гекса высотой 72 пикселя, baseline, порядок семейства,
локальный порядок и один либо несколько кадров анимации.

Используются два terrain-прохода:

- `Ground` рисуется в порядке `(family_order, local_order, y, x)`;
- `World` рисуется по `(screen_y + baseline, family_order, local_order, x)`.

Каждый кадр ссылается на логический id из реестра ресурсов. Неизвестный id,
пустая анимация, нулевая длительность кадра и повторный id ресурса являются
ошибками компиляции сцены.

Сейчас `Game` возвращает пустую `TerrainScene`, а цветные гексы остаются
временным fallback. Семейства будут подключаться к этому контракту по одному.
