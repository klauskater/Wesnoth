# Контракты скриптов Wesnoth

> [!WARNING]
> **Статус: устаревший справочный материал.** Это описание API официального
> Wesnoth используется только для ознакомления и поиска требований. Оно не
> задаёт архитектуру и публичный API нового движка. Новые контракты будут
> выводиться из небольших вертикальных сценариев.

Контракт — это договор между скриптом и программой. Он отвечает на три простых
вопроса:

1. Что скрипт может попросить у программы?
2. Какие данные он должен передать?
3. Что программа обязана вернуть или изменить?

Например, контракт `wesnoth.units.get(x, y)` говорит: скрипт передаёт
координаты, а игровая система возвращает юнита в этой ячейке либо `nil`, если
ячейка пуста. Как именно юнит хранится внутри программы, контракт не определяет.

Эта папка — список таких договоров между Lua/WML и официальным Wesnoth. Список
снят с версии `e97a4190`. Пока мы ничего не удаляем: сначала фиксируем всё, что
нужно существующим скриптам, а потом решим, что оставить и куда перенести.

## Обозначения

- `⚠` — опасная для разделения граница. Такой контракт нужен скриптам, но его
  нельзя бездумно реализовывать внутри движка: он знает о правилах, платформе,
  вводе-выводе или способен нарушить повторяемость игры.
- `R` — поле можно читать, `W` — записывать, `RW` — и читать, и записывать.
- `config` — дерево WML: атрибуты и упорядоченные вложенные теги.
- `vconfig` — доступное только для чтения WML-дерево с подстановкой переменных.
- `location` — координата шестиугольной ячейки.
- `filter` — WML-описание того, какие объекты требуется выбрать.
- `nil` — объект не найден, если отдельно не указано, что это ошибка.

## Предварительное разделение ответственности

| Часть | За что отвечает |
| --- | --- |
| `engine` | Lua VM, значения WML, универсальное хранение карты, порядок изменений |
| `rules` | юниты, смысл местности, стороны, бой, фильтры, сценарии и события |
| `platform` | изображение, ввод, окна, звук, файлы и переводы |
| `deferred` | сохранения, сеть, достижения и ИИ — это понадобится позже |

Это ещё не окончательное решение. Пометки помогают увидеть, какие возможности
официальный Wesnoth смешивает внутри одного объекта `wesnoth`.

`⚠` не означает «удалить». Обычно это означает «оставить Lua-контракт, но
реализовать его адаптером или слоем правил, а не ядром карты».

## Откуда взят список

- `src/scripting/game_lua_kernel.cpp` — игровое API Lua.
- `src/scripting/lua_kernel_base.cpp` — базовая среда Lua и геометрия карты.
- `src/scripting/lua_{unit,unit_attacks,unit_type,team,terrainmap}.cpp` — игровые
  объекты и их поля.
- `src/scripting/lua_{wml,fileops,gui2,audio,rng}.cpp` — служебные модули.
- `data/lua/core/*.lua` — публичные обёртки и старые имена API.
- `data/lua/wml*.lua`, `data/lua/wml/*.lua` — команды WML на Lua.
- `src/game_events/action_wml.cpp` — команды WML на C++.
