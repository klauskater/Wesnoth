# Контракты нового движка

Это актуальные контракты, полученные из сценария
`scripts/scenarios/first_battle.wml`. Они описывают только уже понадобившиеся
возможности. Полный API официального Wesnoth сохранён в `old_contracts` только
для справки.

## Главное правило

Движок знает о WML-деревьях, Lua, карте, универсальных объектах и сообщениях.
Он не знает, что объект является юнитом, что `hitpoints` означает здоровье,
что `grassland` — равнина и как рассчитывается бой.

## Документы

- [scenario-data.md](scenario-data.md) — входные WML-данные первого сценария.
- [world.md](world.md) — универсальная карта и хранилище объектов.
- [lua-runtime.md](lua-runtime.md) — минимальный контекст для Lua-правил.
- [platform.md](platform.md) — команды снаружи и события наружу.
- [first-battle.md](first-battle.md) — полный проход и критерии готовности.
- [campaign.md](campaign.md) — переход между адаптированными сценариями и recall.

## Как развивать

Новый метод или тип сообщения добавляется только тогда, когда без него нельзя
выразить следующий сценарий. Изменение сначала появляется здесь как контракт,
затем в тесте и только потом в реализации.
