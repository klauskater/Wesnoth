# Контракты движка и клиента

Эти документы описывают фактическую публичную границу текущего движка, Lua-
правил и платформенного клиента. `old_contracts/` относится к официальному
Wesnoth и хранится только как справочный материал: порт ему не соответствует.

## Границы системы

- Rust хранит универсальные карту, объекты, состояние и детерминированный RNG.
- WML задаёт статические данные сценария; его полный формат описан в
  [`../docs/wml-reference.md`](../docs/wml-reference.md).
- Lua определяет игровую семантику, проверяет команды и изменяет мир.
- Клиент запрашивает доступные действия и отображает полученные события, не
  дублируя правила игры.

## Правило изменения

Изменение публичного поведения считается законченным, когда одновременно
обновлены реализация, соответствующий контракт и минимальный проверяющий тест.
Если они расходятся, фактическое поведение определяет реализация, а расхождение
считается дефектом контракта или теста, который нельзя оставлять намеренно.
