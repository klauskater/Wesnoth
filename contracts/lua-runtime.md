# Контракт Lua-хоста

Lua-модуль правила возвращает таблицу функций. Первый модуль предоставляет:

```lua
combat.resolve(context, command) -> battle_result
```

## `context`

Хост передаёт только три универсальные службы:

- `context.map` — чтение карты и геометрия из `world.md`;
- `context.objects` — чтение и изменение универсальных объектов;
- `context.random:integer(min, max)` — целое число из детерминированного
  генератора сценария.

Lua не получает файловую систему, системное время, UI, звук или глобальное
изменяемое состояние. Все зависимости видны в `context`.

## Транзакция команды

Один вызов правила выполняется как транзакция. Если Lua завершился ошибкой,
изменения объектов откатываются и наружу выходит ошибка команды. При успехе
изменения фиксируются вместе с возвращённым результатом.

Генератор случайных чисел создаётся из `scenario.random_seed`. Откат команды
также откатывает его состояние.
