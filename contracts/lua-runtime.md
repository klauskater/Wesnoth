# Контракт Lua-хоста

Статус: переходное описание текущего API; разделы VM/транзакции сверены с кодом.
Целевые контракты: [runtime](target/modules/engine/runtime.md),
[store](target/modules/engine/store.md), [entry](target/modules/lua/entry.md).

`Engine::new` создаёт Lua 5.4 VM один раз, исполняет объединённый chunk
файлов из `[resources].rules` и сохраняет возвращённую таблицу в registry.
`execute/query` переиспользуют VM и вызывают `function(context, command)`
с новым транзакционным контекстом. Модули пока загружаются текстовой склейкой.

## Доступная среда

VM создаётся с безопасной стандартной библиотекой. Глобальные `io`, `os`,
`package`, `dofile`, `loadfile` и `require` удалены. Правила не получают UI,
файловую систему или системное время. VM постоянная, поэтому globals/upvalues
технически могут сохраняться между вызовами; их изменения не откатываются
транзакцией Rust. Авторитетное состояние в них хранить нельзя.

Хост передаёт службы:

- `context.objects:get/set/add/remove/all` — универсальные объекты;
- `context.state:get/set` — изменяемое состояние сценария;
- `context.map:get/are_adjacent/neighbors/search` — нормализованная карта,
  геометрия и пакетный поиск пути;
- `context.combat:impact/forecast` — существующий Rust-расчёт боя; его перенос
  в Lua запланирован, универсальным ядром этот API не считается;
- `context.random:integer(min,max)` — детерминированное целое в замкнутом
  диапазоне; `min > max` является ошибкой.

Точные операции мира описаны в [world.md](world.md).

## Значения

Граница принимает и возвращает `Nil`, `Bool`, `Integer`, `String`, `List` и
`Map<String, Value>`. Неподдерживаемое Lua-значение завершает вызов ошибкой.
WML-дерево передаётся как карты атрибутов и `__children`, описанные в
[`../docs/wml-reference.md`](../docs/wml-reference.md).

## Транзакция

Перед вызовом транзакция разделяет `Rc<World>` и копирует состояние RNG.
Первая запись копирует изменяемый мир через `Rc::make_mut`; чтения его не копируют.
Каталоги `unit_types/races/traits` вынесены в разделяемое состояние.
При успехе `execute` принимает мир и RNG транзакции. При ошибке Lua, неизвестной функции, неверном
аргументе или неподдерживаемом результате не фиксируется ничего, включая уже
полученные случайные числа.

`Game::execute` вызывает правило на настоящем движке. Если результат — список,
его элементы становятся событиями; одиночное значение оборачивается в список.
`Game::query` делегирует `Engine::query`: выполняется та же evaluate-транзакция,
но её мир и RNG не фиксируются. Запись в query пока технически доступна;
целевой read-only контекст должен запретить её. Это не откат Lua globals.

## Текущий модуль правил

`basic_combat.lua` предоставляет:

- жизненный цикл: `initialize`, `snapshot`, `status`;
- запросы: `actions`, `reachable`, `preview_attack`;
- команды: `move`, `resolve`, `end_turn`, `recruit`, `recall`, `advance`,
  `choose`;
- функции для составного AI: `are_enemies`, `can_see`.

Форма публичных клиентских команд и результатов зафиксирована в
[platform.md](platform.md). Внутренние функции AI не являются командной
границей `Game`.
