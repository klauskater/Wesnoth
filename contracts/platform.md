# Контракт платформы

Движок не показывает окна и не читает устройства ввода. Платформа отправляет
команды и получает сообщения с обычными WML-совместимыми данными.

## Входящая команда

Граница Rust не содержит перечисления игровых команд или атрибутов сущности:

```text
query(function_name, Value) -> Value
execute(function_name, Value) -> [Value]
acknowledge_dialog()
```

Имена функций и форма `Value` принадлежат Lua-правилам. Приведённые ниже
структуры — контракты текущего сценария, которые разбирает конкретная
платформа, а не типы универсального движка.

Для построения доступного интерфейса платформа запрашивает Lua:

```text
Actions { object } -> {
  reachable: [{ position, cost, path }],
  targets: [object_id],
  attacks: [weapon_id]
}
Status -> { turn, active_side, finished, can_end_turn }
```

Платформа не рассчитывает доступность объекта, клетки, цели, оружия или конца
хода из HP, MP, AP, стороны либо геометрии карты. Она только отображает варианты,
которые вернули Lua-правила, и отправляет выбранную команду.

```text
Continue
```

`DialogRequested` передаёт управление платформе. Пока платформа не отправит
`Continue` после последней реплики, движок отклоняет игровые команды.

```text
Attack {
  attacker: object_id,
  defender: object_id,
  weapon: string
}
```

```text
Move {
  object: object_id,
  destination: { x, y }
}
```

```text
EndTurn
```

Lua проверяет активную сторону, выполняет ходы сторон под управлением ИИ и
возвращает управление следующей стороне человека. Номер хода, активная сторона,
восстановление ресурсов и решения ИИ не интерпретируются Rust-кодом.

Команда ничего не знает о мыши, клавиатуре или координатах экрана.

## Исходящие сообщения

`DialogRequested`:

```text
{ dialog, lines: [{ speaker, text }] }
```

`BattleResolved`:

```text
{
  attacker, defender,
  strikes: [{ number, source, target, weapon, chance, roll,
              hit, damage, target_hitpoints }],
  defeated
}
```

`ObjectMoved`:

```text
{
  object,
  from: { x, y },
  to: { x, y },
  path: [{ x, y }],
  cost,
  movement_points
}
```

`UnitDied`:

```text
{ unit, side, position: { x, y } }
```

После этого события объект отсутствует в снимке мира и больше не занимает клетку.

`TurnStarted` / `TurnEnded`:

```text
{ turn, side }
```

Для подсветки платформа запрашивает у адаптера сценария достижимые клетки.
Каждая клетка содержит позицию, суммарную стоимость и кратчайший путь. Расчёт
проходимости остаётся в Lua-правилах; платформа его только отображает.

`ScenarioFinished`:

```text
{ result: "victory" | "defeat", dialog }
```

Порядок сообщений сохраняется. Визуализатор может анимировать `strikes`, но
анимация не влияет на состояние и не блокирует транзакцию боя.
После `ScenarioFinished` игровые команды отклоняются; снимок и статус остаются
доступны платформе.
