# Каталог приключений

Статус: переходная документация прежнего API и семантики игры;
полный аудит соответствия коду ещё не завершён. Целевые межмодульные границы
и владельцы описаны в [реестре контрактов](target/README.md#прежние-документы).

Клиент не содержит списка приключений. На десктопе он перечисляет файлы
`scripts/adventures/*.wml`; Android-сборка перечисляет те же файлы среди
встроенных ресурсов.

Каждый файл содержит ровно один корневой блок `[adventure]`:

- `id` — стабильный идентификатор;
- `name` — отображаемое название;
- `description` — описание;
- один или несколько дочерних блоков `[scenario]` с атрибутом `path`.

Порядок блоков `[scenario]` задаёт порядок прохождения. Клиент выбирает
приключение целиком и не предлагает запускать отдельную главу.
