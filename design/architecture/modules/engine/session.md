# engine/session

Статус: реализован; Session владеет commit, revision/dedup, viewer contexts,
interact/present, snapshot, save и atomic restore. Именованного query в Session нет:
Game-адаптер преобразует чтение в Interaction/ViewBlock. Open не публикует
полуинициализированную сессию; restore меняет session identity после валидации.

Файл реализации: `src/engine/session.rs`.

и «Граница ответственности» в его модульный комментарий: `//!` для Rust,
