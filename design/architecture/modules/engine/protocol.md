# engine/protocol

Статус: частично реализован; строгий wire envelope, общие сообщения/валидация,
package-aware asset references, базовое дерево UiNode и SceneItem редакции 1
с клиентскими потребителями готовы; UI layout/style и прочие scene-слои ещё
переносятся.

Файл реализации: `src/engine/protocol.rs`.

## Ответственность

Общий словарь границы движок–клиент.

## Контракт

[engine/protocol](../../../../contracts/target/modules/engine/protocol.md) — операции, входы/выходы,
гарантии, ошибки и связи с потребителями. Статус: частично реализован.
API определён в контракте; эта карточка описывает архитектурную ответственность.

## Данные и владение

Владеет схемой сообщений; игровое содержимое action/payload непрозрачно.

## Разрешённые зависимости

Нет зависимостей от реализации движка, клиента или игры.

## Граница ответственности

HP, время суток, end_turn и названия семейств terrain не являются вариантами Rust enum.

## Проверка при переносе

Сообщение другой игры проходит тот же сериализатор и валидатор.

При создании файла реализации перенести разделы «Ответственность», «Данные и владение»
и «Граница ответственности» в его модульный комментарий: `//!` для Rust,
`--` для Lua. Добавить ссылку на контракт выше. Синхронно обновить эту карточку и контракт.
