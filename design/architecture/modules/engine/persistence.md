# engine/persistence

Статус: реализован; Session сохраняет и атомарно восстанавливает StoreSnapshot
без initialize, с проверкой package identity и read-only Lua-валидацией.

Файл реализации: `src/engine/persistence.rs`.

## Ответственность

Запись и восстановление согласованного снимка сессии.

## Контракт

[engine/persistence](../../../../contracts/target/modules/engine/persistence.md) — операции, входы/выходы,
гарантии, ошибки и связи с потребителями. Статус: реализован.
API определён в контракте; эта карточка описывает архитектурную ответственность.

## Данные и владение

Формат сохранения. Сценарий, pending choices и переносимые бойцы — непрозрачные данные store.

## Разрешённые зависимости

store, resources, value.

## Граница ответственности

Не выбирает переносимых ветеранов, размер золота или следующую главу. Не сохраняет кеш UI и текстуры.

## Откуда переносить

SavedGame и save/load_save в src/game.rs

## Проверка при переносе

Сохранение посреди выбора восстанавливает выбор; продолжение воспроизводит RNG. Несовместимая версия не загружается молча.

При создании файла реализации перенести разделы «Ответственность», «Данные и владение»
и «Граница ответственности» в его модульный комментарий: `//!` для Rust,
`--` для Lua. Добавить ссылку на контракт выше. Синхронно обновить эту карточку и контракт.
