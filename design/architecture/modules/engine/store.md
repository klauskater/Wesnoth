# engine/store

Статус: реализован; адресный API, атомарные Tx, revision, ChangeSet и RNG готовы;
commit принадлежит engine/session, карта предоставляет только raw cells.

Файл реализации: `src/engine/store.rs`.

## Ответственность

Единственное авторитетное хранилище изменяемых данных игры.

## Контракт

[engine/store](../../../../contracts/target/modules/engine/store.md) — операции, входы/выходы,
гарантии, ошибки и связи с потребителями. Статус: реализован.
API определён в контракте; эта карточка описывает архитектурную ответственность.

## Данные и владение

Объекты, именованные записи, ревизия мира и RNG; транзакция владеет незавершёнными записями и состоянием RNG.

## Разрешённые зависимости

value; hex для координат. Не зависит от Lua.

## Граница ответственности

Не интерпретирует игровые поля. Не хранит UI. Не предоставляет прямую изменяемую ссылку на мир клиенту.

## Откуда переносить

src/engine.rs: World, Object, Transaction, DeterministicRandom

## Проверка при переносе

Ошибка после нескольких записей и RNG не меняет ни мир, ни последующую случайную последовательность.

При создании файла реализации перенести разделы «Ответственность», «Данные и владение»
и «Граница ответственности» в его модульный комментарий: `//!` для Rust,
`--` для Lua. Добавить ссылку на контракт выше. Синхронно обновить эту карточку и контракт.
