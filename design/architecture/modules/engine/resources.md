# engine/resources

Статус: реализован; package manifest, text/data/module и проверяемый asset registry подключены.

Файл реализации: `src/engine/resources.rs`.

## Ответственность

Доступ к содержимому сменяемого пакета игры.

## Контракт

[engine/resources](../../../../contracts/target/modules/engine/resources.md) — операции, входы/выходы,
гарантии, ошибки и связи с потребителями. Статус: реализован.
API определён в контракте; эта карточка описывает архитектурную ответственность.

## Данные и владение

Неизменяемые ресурсы пакета; manifest содержит package_id, version, entry, resource roots, protocol_version.

## Разрешённые зависимости

data_format; платформенный файловый или embedded источник.

## Граница ответственности

Не сливает unit_type/race/trait и не ищет деревни. Не компилирует сценарные правила в Rust.

## Откуда переносить

src/embedded.rs; загрузка файлов в src/game.rs; build.rs

## Проверка при переносе

Один пакет одинаково читается с диска и из embedded; путь за пределы пакета отклоняется.

При создании файла реализации перенести разделы «Ответственность», «Данные и владение»
и «Граница ответственности» в его модульный комментарий: `//!` для Rust,
`--` для Lua. Добавить ссылку на контракт выше. Синхронно обновить эту карточку и контракт.
