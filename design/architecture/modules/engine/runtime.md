# engine/runtime

Статус: реализован; VM, package require, typed entry-входы, typed budget error, read-only capabilities,
лимит инструкций и истечение ctx готовы, Store/commit принадлежат Session.

Файл реализации: `src/engine/runtime.rs`.

## Ответственность

Исполнение модулей Lua с ограниченными возможностями доступа.

## Контракт

[engine/runtime](../../../../contracts/target/modules/engine/runtime.md) — операции, входы/выходы,
гарантии, ошибки и связи с потребителями. Статус: реализован.
API определён в контракте; эта карточка описывает архитектурную ответственность.

## Данные и владение

Одна постоянная VM на сессию; кеш загруженных модулей, но не второе игровое состояние.

## Разрешённые зависимости

store, resources, hex, pathfinding, value.

## Граница ответственности

Нет произвольного доступа к файлам/сети; require только внутри пакета. Нет отдельной VM или загрузки исходников на каждый клик.

## Откуда переносить

src/engine.rs: Lua/evaluate/create_context; склейка rules в src/game.rs

## Проверка при переносе

Повторный импорт возвращает тот же модуль; циклический импорт выдаёт понятную ошибку; present не может записывать данные.

При создании файла реализации перенести разделы «Ответственность», «Данные и владение»
и «Граница ответственности» в его модульный комментарий: `//!` для Rust,
`--` для Lua. Добавить ссылку на контракт выше. Синхронно обновить эту карточку и контракт.
