# engine/value

Статус: реализован; модуль и потребители используют строгий Value bridge с
явными Lua-конструкторами list/record/null.

Файл реализации: `src/engine/value.rs`.

## Ответственность

Общие сериализуемые значения и преобразование на границе Lua.

## Контракт

[engine/value](../../../../contracts/target/modules/engine/value.md) — операции, входы/выходы,
гарантии, ошибки и связи с потребителями. Статус: реализован.
API определён в контракте; эта карточка описывает архитектурную ответственность.

## Данные и владение

Представление чисел, строк, списков, записей и null.

## Разрешённые зависимости

Только библиотеки сериализации и Lua bridge.

## Граница ответственности

Не содержит методов unit.hp или толкования игровых полей.

## Откуда переносить

src/value.rs

## Проверка при переносе

Вложенное значение сохраняет типы при round trip; неподдерживаемое значение приводит к ошибке до commit.

При создании файла реализации перенести разделы «Ответственность», «Данные и владение»
и «Граница ответственности» в его модульный комментарий: `//!` для Rust,
`--` для Lua. Добавить ссылку на контракт выше. Синхронно обновить эту карточку и контракт.
