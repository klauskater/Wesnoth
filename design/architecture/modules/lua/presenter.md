# lua/presenter

Статус: частично реализован: presenter собирает status/objects/HUD/time, статическую
scene, map/assets, диалоги, эффекты, выбор с готовыми строками местности/юнита,
навигацию доступных юнитов, маршрут с защитой, attack, summary, unit и recruit-блоки;
динамическая сцена и полная viewer-фильтрация ещё переносятся.

Файл реализации: `scripts/game/presentation/presenter.lua`.

## Ответственность

Сборка представления конкретного наблюдателя после изменения мира или взаимодействия.

## Контракт

[lua/presenter](../../../../contracts/target/modules/lua/presenter.md) — операции, входы/выходы,
гарантии, ошибки и связи с потребителями. Статус: частично реализован.
API определён в контракте; эта карточка описывает архитектурную ответственность.

## Данные и владение

Кеши блоков по world_revision, viewer и interaction_revision; всё можно пересоздать.

## Разрешённые зависимости

map, hud, effects; rules/visibility. Interaction вызывается через отдельный entry.interact.

## Граница ответственности

Не меняет мир и RNG. При неизвестной зависимости перестраивает блок, а не оставляет устаревшее значение.

## Откуда переносить

basic_combat.snapshot/status/actions; GameSnapshot; screens/game.rs

## Проверка при переносе

Смена выбора обновляет UI без world commit; ошибка построения допускает повторный present.

При создании файла реализации перенести разделы «Ответственность», «Данные и владение»
и «Граница ответственности» в его модульный комментарий: `//!` для Rust,
`--` для Lua. Добавить ссылку на контракт выше. Синхронно обновить эту карточку и контракт.
