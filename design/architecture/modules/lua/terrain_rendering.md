# lua/terrain_rendering

Статус: целевой модуль, перенос реализации ещё не выполнен.

Файл реализации: `scripts/game/presentation/terrain/init.lua`.

## Ответственность

Сборка визуальных семейств местности и их порядка.

## Контракт

[lua/terrain_rendering](../../../../contracts/target/modules/lua/terrain_rendering.md) — операции, входы/выходы,
гарантии, ошибки и связи с потребителями. Статус: целевой, не реализован.
API определён в контракте; эта карточка описывает архитектурную ответственность.

## Данные и владение

Порядок семейств и область перестройки, включая соседей для переходов.

## Разрешённые зависимости

Семейства: grass.lua, hills.lua, water.lua, forest.lua, road.lua, dirt.lua, decorations.lua, bridges.lua, castles.lua.

## Граница ответственности

Каждое семейство отвечает только за свои спрайты/переходы; не задаёт defense/MP. Новая система визуальных правил не требуется.

## Откуда переносить

scripts/terrain/*.lua; src/terrain_rules.rs; src/terrain_scene.rs

## Проверка при переносе

Изменение ячейки обновляет и зависимые переходы соседей; сохраняется существующий порядок спрайтов.

При создании файла реализации перенести разделы «Ответственность», «Данные и владение»
и «Граница ответственности» в его модульный комментарий: `//!` для Rust,
`--` для Lua. Добавить ссылку на контракт выше. Синхронно обновить эту карточку и контракт.
