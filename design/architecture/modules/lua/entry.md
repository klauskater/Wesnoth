# lua/entry

Статус: частично реализован; четыре entry-входа подключены, dispatch пока
делегирует прежним правилам.

Файл реализации: `scripts/game/init.lua`.

## Ответственность

Единственная внешняя точка входа пакета и явная сборка модулей.

## Контракт

[lua/entry](../../../../contracts/target/modules/lua/entry.md) — операции, входы/выходы,
гарантии, ошибки и связи с потребителями. Статус: целевой, не реализован.
API определён в контракте; эта карточка описывает архитектурную ответственность.

## Данные и владение

Таблица экспортов и ссылки на модули; авторитетного состояния в upvalues нет.

## Разрешённые зависимости

bootstrap, flow, presentation/presenter, presentation/interaction.

## Граница ответственности

Не содержит формул боя или вёрстки; не склеивает файлы текстом. Модули возвращают локальные таблицы через контролируемый require.

## Откуда переносить

return combat и общая таблица basic_combat.lua; склейка rules в game.rs

## Проверка при переносе

Внешняя граница остаётся одинаковой при замене пакета.

При создании файла реализации перенести разделы «Ответственность», «Данные и владение»
и «Граница ответственности» в его модульный комментарий: `//!` для Rust,
`--` для Lua. Добавить ссылку на контракт выше. Синхронно обновить эту карточку и контракт.
