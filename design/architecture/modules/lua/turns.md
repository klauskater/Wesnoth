# lua/turns

Статус: целевой модуль, перенос реализации ещё не выполнен.

Файл реализации: `scripts/game/rules/turns.lua`.

## Ответственность

Очередность ходов и процедуры их начала/окончания.

## Контракт

[lua/turns](../../../../contracts/target/modules/lua/turns.md) — операции, входы/выходы,
гарантии, ошибки и связи с потребителями. Статус: целевой, не реализован.
API определён в контракте; эта карточка описывает архитектурную ответственность.

## Данные и владение

Номер хода и активная сторона в store; порядок локальных процедур хода.

## Разрешённые зависимости

sides, time, economy, units, terrain.

## Граница ответственности

Не запускает полный AI-ход и не обрабатывает сценарные триггеры; возвращает события flow.

## Откуда переносить

reset_side/start_side/finish_side/end_turn в basic_combat.lua

## Проверка при переносе

Доход, лечение, истечение статусов и переход суток происходят ровно один раз в нужной фазе.

При создании файла реализации перенести разделы «Ответственность», «Данные и владение»
и «Граница ответственности» в его модульный комментарий: `//!` для Rust,
`--` для Lua. Добавить ссылку на контракт выше. Синхронно обновить эту карточку и контракт.
