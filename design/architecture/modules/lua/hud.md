# lua/hud

Статус: частично реализован: end-turn опубликован как общий UiNode; остальные
игровые панели и обязательные выборы ещё переносятся.

Файл реализации: `scripts/game/presentation/hud.lua`.

## Ответственность

Описание игрового интерфейса и игровых меню через общие UiNode.

## Контракт

[lua/hud](../../../../contracts/target/modules/lua/hud.md) — операции, входы/выходы,
гарантии, ошибки и связи с потребителями. Статус: частично реализован.
API определён в контракте; эта карточка описывает архитектурную ответственность.

## Данные и владение

Тексты, assets, layout декларации и action payload; отдельные layout-ресурсы допустимы.

## Разрешённые зависимости

rules/time, units, economy, combat, forecast, sides; scenario, campaign.

## Граница ответственности

Не задаёт игровые формулы, не принимает решение о допустимости команды вместо rules. Пока панели — локальные функции одного файла.

## Откуда переносить

basic_combat.status/unit_option; time_info/time_tint и панели screens/game.rs; screens/adventures.rs

## Проверка при переносе

В Rust отсутствуют чтения time_of_day/hitpoints/gold для UI; конец хода — обычный action.

При создании файла реализации перенести разделы «Ответственность», «Данные и владение»
и «Граница ответственности» в его модульный комментарий: `//!` для Rust,
`--` для Lua. Добавить ссылку на контракт выше. Синхронно обновить эту карточку и контракт.
