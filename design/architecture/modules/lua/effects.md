# lua/effects

Статус: целевой модуль, перенос реализации ещё не выполнен.

Файл реализации: `scripts/game/presentation/effects.lua`.

## Ответственность

Перевод игровых событий в видимые одноразовые эффекты.

## Контракт

[lua/effects](../../../../contracts/target/modules/lua/effects.md) — операции, входы/выходы,
гарантии, ошибки и связи с потребителями. Статус: целевой, не реализован.
API определён в контракте; эта карточка описывает архитектурную ответственность.

## Данные и владение

Визуальный язык игры; effects связаны с committed command id и индексом.

## Разрешённые зависимости

rules/visibility; ресурсы анимаций.

## Граница ответственности

Не меняет HP и не рассчитывает бой. Скрытый бой не раскрывается через звук/координаты; политика видимости явно задана игрой.

## Откуда переносить

client/battle.rs, movement.rs; трактовка domain events клиентом

## Проверка при переносе

Повторный present не создаёт новые ids для тех же эффектов; сохранение не повторяет уже прошедшую анимацию.

При создании файла реализации перенести разделы «Ответственность», «Данные и владение»
и «Граница ответственности» в его модульный комментарий: `//!` для Rust,
`--` для Lua. Добавить ссылку на контракт выше. Синхронно обновить эту карточку и контракт.
