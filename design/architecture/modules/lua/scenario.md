# lua/scenario

Статус: целевой модуль, перенос реализации ещё не выполнен.

Файл реализации: `scripts/game/scenario.lua`.

## Ответственность

Сценарные триггеры, цели, диалоги и обязательные выборы.

## Контракт

[lua/scenario](../../../../contracts/target/modules/lua/scenario.md) — операции, входы/выходы,
гарантии, ошибки и связи с потребителями. Статус: целевой, не реализован.
API определён в контракте; эта карточка описывает архитектурную ответственность.

## Данные и владение

Переменные сценария, обработанные триггеры, pending choice/dialog, результат в store.

## Разрешённые зависимости

rules/units, sides, terrain; без flow и presentation.

## Граница ответственности

Не вызывает flow рекурсивно: возвращает follow-up действия. Не выбирает клиентский экран напрямую.

## Откуда переносить

objective_event/turn_event/location_event/choose; DialogLine/pending_dialog в game.rs

## Проверка при переносе

Событие не срабатывает повторно после сохранения; обязательный выбор блокирует неподходящие команды.

При создании файла реализации перенести разделы «Ответственность», «Данные и владение»
и «Граница ответственности» в его модульный комментарий: `//!` для Rust,
`--` для Lua. Добавить ссылку на контракт выше. Синхронно обновить эту карточку и контракт.
