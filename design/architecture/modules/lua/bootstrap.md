# lua/bootstrap

Статус: целевой модуль, перенос реализации ещё не выполнен.

Файл реализации: `scripts/game/bootstrap.lua`.

## Ответственность

Преобразование декларативных данных именно этой игры в начальный мир.

## Контракт

[lua/bootstrap](../../../../contracts/target/modules/lua/bootstrap.md) — операции, входы/выходы,
гарантии, ошибки и связи с потребителями. Статус: целевой, не реализован.
API определён в контракте; эта карточка описывает архитектурную ответственность.

## Данные и владение

Схема и начальные значения сценария/каталогов. Каталоги неизменяемы и доступны отдельно от mutable state.

## Разрешённые зависимости

rules/units, rules/terrain, scenario, campaign; read-only resources API.

## Граница ответственности

Не рисует интерфейс. Парсинг синтаксиса остаётся в Rust; толкование тегов здесь.

## Откуда переносить

Game::load_with_campaign_from; basic_combat.initialize

## Проверка при переносе

Расы, traits, деревни и стартовое золото определяются без знания этих слов в Rust.

При создании файла реализации перенести разделы «Ответственность», «Данные и владение»
и «Граница ответственности» в его модульный комментарий: `//!` для Rust,
`--` для Lua. Добавить ссылку на контракт выше. Синхронно обновить эту карточку и контракт.
