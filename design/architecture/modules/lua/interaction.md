# lua/interaction

Статус: целевой модуль, перенос реализации ещё не выполнен.

Файл реализации: `scripts/game/presentation/interaction.lua`.

## Ответственность

Игровое значение кликов и контекст просмотра.

## Контракт

[lua/interaction](../../../../contracts/target/modules/lua/interaction.md) — операции, входы/выходы,
гарантии, ошибки и связи с потребителями. Статус: целевой, не реализован.
API определён в контракте; эта карточка описывает архитектурную ответственность.

## Данные и владение

Схема selected/hovered/modal контекста конкретного наблюдателя; хранит его session отдельно от мира.

## Разрешённые зависимости

rules/movement, combat, economy, visibility, sides.

## Граница ответственности

Не применяет игровую command непосредственно и не решает координаты пикселей. Команда возвращается в session и проходит dispatch.

## Откуда переносить

логика выбора/движения/атаки screens/game.rs; basic_combat.actions

## Проверка при переносе

Тот же клик в другой игре может значить другое без правки клиента; скрытый объект нельзя выбрать по id.

При создании файла реализации перенести разделы «Ответственность», «Данные и владение»
и «Граница ответственности» в его модульный комментарий: `//!` для Rust,
`--` для Lua. Добавить ссылку на контракт выше. Синхронно обновить эту карточку и контракт.
