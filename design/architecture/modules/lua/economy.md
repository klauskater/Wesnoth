# lua/economy

Статус: целевой модуль, перенос реализации ещё не выполнен.

Файл реализации: `scripts/game/rules/economy.lua`.

## Ответственность

Золото, доход, содержание, владение деревнями и найм/возврат.

## Контракт

[lua/economy](../../../../contracts/target/modules/lua/economy.md) — операции, входы/выходы,
гарантии, ошибки и связи с потребителями. Статус: целевой, не реализован.
API определён в контракте; эта карточка описывает архитектурную ответственность.

## Данные и владение

Золото, владельцы деревень и резерв в store; стоимость и ограничения найма.

## Разрешённые зависимости

units, sides, terrain.

## Граница ответственности

Не отображает магазин и не переносит кампанию. Нельзя доверять цене, переданной клиентом.

## Откуда переносить

economy/village_at/recruitment_hexes/recruit/recall в basic_combat.lua

## Проверка при переносе

Невалидный найм не списывает золото; recruit_options согласован с recruit.

При создании файла реализации перенести разделы «Ответственность», «Данные и владение»
и «Граница ответственности» в его модульный комментарий: `//!` для Rust,
`--` для Lua. Добавить ссылку на контракт выше. Синхронно обновить эту карточку и контракт.
