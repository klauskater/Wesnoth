# client/effects

Статус: целевой модуль, перенос реализации ещё не выполнен.

Файл реализации: `src/bin/client/effects.rs`.

## Ответственность

Воспроизведение одноразовых визуальных и звуковых эффектов.

## Контракт

[client/effects](../../../../contracts/target/modules/client/effects.md) — операции, входы/выходы,
гарантии, ошибки и связи с потребителями. Статус: целевой, не реализован.
API определён в контракте; эта карточка описывает архитектурную ответственность.

## Данные и владение

Локальная временная шкала и проигрываемые эффекты.

## Разрешённые зависимости

view, scene, engine/protocol.

## Граница ответственности

Не применяет урон и не задерживает commit до конца анимации. Не интерпретирует unit_killed: Lua переводит это в визуальный эффект.

## Откуда переносить

src/bin/client/battle.rs; movement.rs

## Проверка при переносе

Повторная доставка effect_id не воспроизводит его дважды; пропуск анимации не меняет мир.

При создании файла реализации перенести разделы «Ответственность», «Данные и владение»
и «Граница ответственности» в его модульный комментарий: `//!` для Rust,
`--` для Lua. Добавить ссылку на контракт выше. Синхронно обновить эту карточку и контракт.
