# client/view

Статус: частично реализован: атомарный кеш и восстановление snapshot готовы,
status/objects GameScreen читаются из него; универсальные UI/scene узлы ещё впереди.

Файл реализации: `src/bin/client/view.rs`.

## Ответственность

Локальная копия готового представления для отрисовки.

## Контракт

[client/view](../../../../contracts/target/modules/client/view.md) — операции, входы/выходы,
гарантии, ошибки и связи с потребителями. Статус: частично реализован.
API определён в контракте; эта карточка описывает архитектурную ответственность.

## Данные и владение

Дерево UI, сцена и их view_revision; это восстанавливаемый кеш.

## Разрешённые зависимости

engine/protocol.

## Граница ответственности

Не вычисляет показатели из игровых данных. world_revision и view_revision различаются.

## Откуда переносить

status/units/snapshot кеши screens/game.rs

## Проверка при переносе

Обновление с чужой base_revision не применяется; полный snapshot восстанавливает согласованное отображение.

При создании файла реализации перенести разделы «Ответственность», «Данные и владение»
и «Граница ответственности» в его модульный комментарий: `//!` для Rust,
`--` для Lua. Добавить ссылку на контракт выше. Синхронно обновить эту карточку и контракт.
