# client/connection

Статус: реализован: команды, interactions, доставки, snapshot, ревизии,
ресурсы сцены, движение и выбор цели атаки подключены через Connection/View.

Файл реализации: `src/bin/client/connection.rs`.

## Ответственность

Адаптация вызовов встроенной сессии к протоколу клиента.

## Контракт

[client/connection](../../../../contracts/target/modules/client/connection.md) — операции, входы/выходы,
гарантии, ошибки и связи с потребителями. Статус: реализован.
API определён в контракте; эта карточка описывает архитектурную ответственность.

## Данные и владение

Состояние подключения, корреляция ответов и ожидаемые ревизии.

## Разрешённые зависимости

engine/session и engine/protocol. Остальные клиентские модули используют только protocol.

## Граница ответственности

Не вызывает именованные внутренние Lua-функции; не читает World. Сетевой транспорт сейчас не реализуется.

## Откуда переносить

прямые вызовы Game в screens/game.rs

## Проверка при переносе

Весь доступ клиента к сессии проходит через этот файл.

При создании файла реализации перенести разделы «Ответственность», «Данные и владение»
и «Граница ответственности» в его модульный комментарий: `//!` для Rust,
`--` для Lua. Добавить ссылку на контракт выше. Синхронно обновить эту карточку и контракт.
