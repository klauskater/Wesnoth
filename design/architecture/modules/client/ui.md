# client/ui

Статус: частично реализован: общий renderer контейнеров, текста, изображений,
tooltip и кнопок подключён к HUD, времени суток, summary, панели юнита, найму и диалогам;
progress, расширенный layout/style и остальные панели ещё переносятся.

Файл реализации: `src/bin/client/ui.rs`.

## Ответственность

Раскладка и отрисовка декларативного интерфейса.

## Контракт

[client/ui](../../../../contracts/target/modules/client/ui.md) — операции, входы/выходы,
гарантии, ошибки и связи с потребителями. Статус: частично реализован.
API определён в контракте; эта карточка описывает архитектурную ответственность.

## Данные и владение

Измерения, layout и локальные состояния виджетов; assets через renderer.

## Разрешённые зависимости

view, engine/protocol.

## Граница ответственности

Нет виджета UnitPanel, TimeOfDay или RecruitButton; подписи и action предоставляет игра.

## Откуда переносить

src/bin/client/widgets.rs; игровые панели screens/game.rs

## Проверка при переносе

Одна схема UI работает при изменении размеров окна без вычисления layout в Lua каждый кадр.

При создании файла реализации перенести разделы «Ответственность», «Данные и владение»
и «Граница ответственности» в его модульный комментарий: `//!` для Rust,
`--` для Lua. Добавить ссылку на контракт выше. Синхронно обновить эту карточку и контракт.
