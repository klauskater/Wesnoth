# Wesnoth Engine

Headless-прототип движка по сценарию «Первая битва».

```powershell
cargo test
cargo run
```

`cargo run` загружает WML из `scripts/`, исполняет правила боя на встроенном
Lua 5.4 и выводит диалоги и журнал ударов в консоль.

## Границы

- `src/engine.rs` — универсальная карта, объекты, RNG и транзакционный Lua-хост;
- `src/game.rs` — адаптер данных текущего игрового сценария;
- `src/wml.rs` — минимальный WML-парсер;
- `scripts/` — игровые данные и правила;
- `contracts/` — актуальные контракты вертикального среза.

Ядро не знает о юнитах, HP, оружии, защите, диалогах или победе. Эти понятия
находятся в адаптере сценария и Lua/WML.
